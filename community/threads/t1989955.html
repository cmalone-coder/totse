Re: anyone here good with C? quick question
Code:
#include<stdio.h>



int main() {

        int foo[4] = {0,1,2,5};

        int bar[2] = {6,9};

        int i;

        for(i=0;foo[i]=bar[i];i++) {

                printf("%i\n", i);

        }

        return 0;

}
That code results in an infinite loop.

So I was wrong, it turns out that your code just results in an infinite loop. It is not a modified version of strcpy() like I initially thought.
