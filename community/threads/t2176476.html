To make sure we cover all bases, you have in fact adjusted your V position and H position in the CRT/LCD menu for the monitor it's self?

If this fails, use: xvidtune
For someone using a dual boot system like myself, if I notice the windowing system positions differ between Windows and Linux, you want to use xvidtune instead of adjusting the position manually.

Your card's video driver name is also: i810
Change this to this: Driver "vesa"
Driver "i810"
Then just restart X, by using ctrl-alt-backspace if you are in runlevel 5, it will restart.. if not run:
init 3 && init 5
after making the changes to X.org configuration.

If you have more problems, or the resolution does not fix, let us know.
