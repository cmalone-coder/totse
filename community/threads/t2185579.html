Re: shoplifting cds from walmart
NO! Magnetic strips, or strong magnets do not effect the quality of a CD/DVD.

CD's save data in a Binary code using the optical surface.
Reflective-open (1)
Non-reflective (0)
As the CD stores the files using the optical surface, a strong magnet will not effect the reflection.

Hard drives can get screwed up by strong magnets though, ast they use a magnetic field to store data.
