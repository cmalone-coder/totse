Passwords are not kept in /etc/passwd on most unix systems anymore. They are kept in /etc/shadow. /etc/shadow has permissions set so non priv users cant read it.

If you are serious about learning REAL unix programming check out Advanced Programming in the Unix Environment by Richard Stevens. It would enable you to learn to write a real working shell/login. I certainly do not agree with you attempting comprimise the security of someone elses machine though. Why would you want to do something like this?

If you want to learn unix set up a linux box at home, all you need is a 386. You can often get them free if you will haul them off for someone.
