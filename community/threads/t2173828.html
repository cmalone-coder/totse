Tell the guy you want to use VNC. It is made specifically for X windowing. You can also use Secure Shell with X window forwarding, but the difference in the two are with secure shell and X forwarding, you only get the application you decide to run as a graphical interface, if it has one.

With VNC, you get the whole X windowing system displayed in the VNC application you choose to use, for Windows I would use a trial version of Hummingbird Exceed.

It is most likely that you can setup a game server with secure shell also, it doesn't have to have graphics to transmit user data to and from client machines that are connected to the game server.

If you would like some help, tell us which game server you are trying to install or create.
