Why are you running last year's OS?

I'm not sure if it's in the 7.04 repos, but lilypond and GTK interfaces to lilypond are in the repositories.

On Gnu, you don't spend ages googling for a program, only to download it and realize it's a virus and start over, and then go through some laborious setup process with "wizards" and "druids" and "knights" or whatever Windows has now. Gnu package installation is simple and magic-free! Each distro has (or points to another distro's) repositories, servers that hold packages. A package is anything that can be installed; GNOME or KDE themes, manuals, documentation, source code, libraries, or programs. These packages are installed with a package manager that allows a user to maintain a clean system with the ability to easily add or remove packages!

Ubuntu has four main interfaces to the package manager they use, which is also used by Debian and many other distros: Apt, the Advanced Package Tool. These are gnome-app-install (Applications>Add/Remove Programs), Synaptic (System>Administration>Synaptic Package Manager), aptitude (an ncurses-based package manager), and apt-get/apt-cache (command-line tools for installing, searching through, or removing packages).

I suggest using gnome-app-install or Synaptic to install lilypond, instead of doing it manually. This will allow you to easily remove lilypond if the time comes, and also allows lilypond to be updated in sync with future releases.
