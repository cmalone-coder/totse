Re: linux
i installed mandrake 6.1 yesterday on my system for the very first time.

i had some problems. during the installation both disk druid and fdisk(linux) gave me errors about not being able to recognize the filesystem. turned out that i had to delete all the existing partitions using fdisk(msdos). luckily i was working on a brand new harddrive and had nothing on it.

here are some things you will need to know about your hardware:
- monitor horizontal and vertical refresh rate
- type of monitor (vga, svga, etc.)
- name and model of video card
- video memory
- type of mouse (ps2, serial, etc)
- keyboard type (qwerty, or some other key arrangement)
- if you have any scsi adapters

you will also be asked to use either disk druid or fdisk(linux) to create your partitions. i suggest you use disk druid because of its graphical interface, whereas fdisk(linux) has a text interface. you'll have to create at least two partitions: swap and a principle partition.

after that it will show the list of packages (software) you want to install. if you are using linux for the first time i suggest you go with the items already selected. same thing goes for the services.

after all that is done you will be asked to chose a root password. the installtion may ask you to create another normal user account. i suggest you use this account for your everyday work and for getting used to linux, just so you dont risk changing any system settings that might effect your system in a bad way.

installing linux is not that hard. you just need to have the basic information about your hardware, and should know a bit about disk partitions.
