And for the billionth time, the operating system is Gnu. The kernel is Linux. If you want to specify you're using Gnu with the Linux kernel (which is valid -- gnu runs on many kernels) then say Gnu/Linux. Saying Linux to describe the system is like saying Darwin when you mean OS X. The OS is not the kernel.
