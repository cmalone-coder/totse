`echo "id:6:initdefault:" >> /etc/inittab`
Use this if you want to be stuck in a reboot loop.

Use a virtual term as pr0n said.
Actually, you could simply edit /etc/inittab and change the default run level to 3, which is what the default should be anyway...
You will need to reboot for the changes to take effect.
If you feel uncomfortable doing this, simply force removal of gdm ( some crap might depend on it ).
That should take you to xdm, or to run level 3, one or the other.
Actually you can do some pretty cool tricks if you know your way around Xorg/Xnest/xinit/[...] and the inittab.
