To convert Fahrenheit to Celsius is very easy to remember, because its the opposite of converting Celsius to Fahrenheit, so your learning both at the same time. Observe:

Fahrenheit to Celsius:
Take the Fahrenheit temperature number and take away 32, multiply the new number by 5, divide this result by nine. The number you have left is the Celsius temperature.

Celsius to Fahrenheit:
Take the Celsius temperature number and MULTIPLY it by nine, DIVIDE the new number by five, then to this result ADD 32. The number you have left is the Fahrenheit temperature.

Re: Simple TI 83 Plus calculator programs
Find somebody with MirageOS or buy a cable and download the program and send it to the calc. MirageOS allows you to protect a program from editing, archive a program (so that it wont be erased on reset (though you can do this in your memory options as well)), hide a program from the program list in TI-OS, and even block the memory option from access (when 2nd + mem is pressed it does nothing). MirageOS is not a program but rather an Application which allows it to run in the archive memory so that it will not be deleted on reset. MirageOS is *the* best for calculator utilities.
