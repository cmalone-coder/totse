Slackware is not very noob-friendly, but depending on where you're getting that error, either the initramfs is FUCKED ROYALLY or you just aren't specifying the root partition on the kernel command line.

Go into the boot loader (pretty much all boot loaders support this) and edit the command line to include "root=<root partition, whatever it is>". However, if the initramfs isn't configured right (no idea how slackware does this) then you're fucked.

Don't listen to the zealots in here.
Slackware would have told you if the /boot or /root (depending if you created a different slice for /boot) wasn't marked as bootable.
The initrd most likely isn't the problem.
And it would have presented you a prompt and not a kernel panic if it didn't find root.
Also, it did found /, it just is not able to mount it...

The disk is a ide, therefore you should have read the documentation and installed the kernel with legacy ide kernel.

It MIGHT be because your system is not multicore ( if it is not ), IIRC the latest slackware install the SMP kernel by default ( when you choose the same kernel as the one it booted with ), which MIGHT cause problem.
From the pic you posted, there does not seem to be a swap partiton, it MIGHT cause problems.

Just reinstall, if you still have the same problem go to the Slackware mailing list.

Also make note of which kernel you install, idiot, Slackware ships with many different kernels, some of which aren't even the same first 2 digits.
( It will prompt during the install )

I might be wrong on some of the things, i didn't gave 12.1 a try yet, you should read the documentation at slackware.com and slackbook.org.
