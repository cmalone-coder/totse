Re: Stop explorer from starting on login
Here's what to do:
  1. Windows key + R, regedit, Enter
  2. Navigate to HKEY_LOCAL_MACHINE \ SOFTWARE \ Microsoft \ Windows NT \ CurrentVersion \ Winlogon
  3. Edit the Shell string to cmd.exe or taskmgr.exe
  4. Close regedit.
  5. Log out.
  6. Log back in.
  7. Different shell.
If you want to change it for JUST yourself and not every other user, go to HKEY_CURRENT_USER (instead of HKEY_LOCAL_MACHINE) and add the Shell string manually in the same path.

You want TrayModule then. Make your startup shell a batch file that first runs TrayModule followed by PowerShell and Steam or whatever else you want.

Code:
@echo off
start /b "" "c:\program files\traymodule.exe"
start /b "" "c:\windows\powershell\powershell.exe"
start /b "" "c:\program files\valve\steam\steam.exe"
Just adjust the above paths to whatever the correct location is.
