Easy read your help file. Here is the related script.

on 1 :DNS:{
var %n = $dns(0)
echo 4 Found %n addresses
while (%n > 0) {
echo 4 dns: $dns(%n) nick: $dns(%n).nick addr: $dns(%n).addr ip: $dns(%n).ip
dec %n
}
}

Re: irc scripting
Looks good, you might want to record a %chan variable to be the channel the bot outputs the message into. If you wanted to you could set it in the on TEXT event. %chan = $chan, that way it can send the message to the channel that requested the DNS in the first place.

code:

ON 10:TEXT:Zokbot, dns*:#:{ 
  if ($2 == dns) { 
    %chan = $chan
    dns $3- 
  } 
}
on 1  :DNS:/msg %chan Resolved: $raddress
;also you probally want these to send to the  
;channel and not echo.
on 1   :DNS:{
  var %n = $dns(0)
  /msg %chan Found %n addresses
  while (%n > 0) {
    /msg %chan dns: $dns(%n) nick: $dns(%n).nick addr: $dns(%n).addr ip: $dns(%n).ip
    dec %n
  }
}

"does the script even have a name asside from mirc script?"

Nope, it's just mirc script.

"Is there any possible way to make a script/alias which will automaticly capitalize the first letter of every sentence and/or put a period...."

Well yes and no.

It is possible to trap messages and format them. It is however not possible to supress mirc from printing the message before you have a chance to print it all formatted.

Here is a script to show you what i mean.
code:

on 1:TEXT:*:*: {
  %text = $right($1-, $calc($len($1-) - 1))
  %l = $upper($left($1, 1))

  echo -a < $+ $nick $+ > %l $+ %text $+ .

  halt       ;does jack shit since we are called after mirc prints
}


Anyways thats something.
