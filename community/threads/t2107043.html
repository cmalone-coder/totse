Your sysconfig/network seems fine.

Run system-config-network . You should be able to edit eth0 and set "Activate device when computer starts".

If that doesn't work, check /etc/sysconfig/networking/devices/ifcfg-eth0 and see if there's a line: "ONBOOT=yes" . If there isn't, try adding it. If it's "ONBOOT=no", try changing it to yes.
