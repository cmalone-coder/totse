To the OP:

Any Gnu distro will do those things. I assume "listening to music" is the usage case, rather than "producing or creating music", so if I'm wrong, then this post is wrong, but otherwise, any distro will do those three things.

Ubuntu will work fine. So will Fedora; with only minimally more work (if any). So will Slackware or Gentoo, with a moderate amount of more work.

I suggest you just install the latest Ubuntu. I've heard about auto-migration features in the installer for the last two or so versions, but never having to migrate myself I don't know how well they work. If you don't feel like doing that, then the external drive will work fine for data transfer.

Here's a hint, though: Format your filesystem with at least a / and a /home partition. This allows you to reinstall the entire OS, while keeping your files and configurations safe from harm. This will come in handy some day if you find the habit now.
