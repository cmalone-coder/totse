Re: *nix Gurus!
You've slightly misunderstood the problem. The ASCII vs Binary issue only comes up when transfering files over FTP. FTP has two transfer modes, ASCII and Binary. If you've uploaded your scripts via FTP make sure they where uploaded using the ASCII transfer method.

Also, I think you have apache mis-configured for your configuration. If you want apache to treat all files with a certain extention as a script, you have to add the following directive to httpd.conf:

code:<pre>AddHandler cgi-script .cgi</pre>

where .cgi is the script extension you want to use.

Re: *nix Gurus!
Another thing to check for is that the scripts are unix text files, not msdos text files. The .zip format is a clue to me that you should at least check it out.

Open a script in a text editor. Is there a ^M at the end of each line? If so, then you will have use a utility like fromdos to convert it.

Edit: You can use the -a option with unzip to convert text files too.
