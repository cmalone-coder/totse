Gnu/Linux is an operating system. It fulfills the same functions as Windows or OS X, and has a lot of features that end up making it faster than both, lighter than both, more secure than both, etc.

If you're installing Gnu/Linux, I recommend you boot off of the gNewSense live CD. If everything works, install that. If some things (like network devices or graphics cards) don't, then install Ubuntu. The reason for that is...

The main asset of Gnu/Linux is freedom. Free software and its development process have a lot of edges over non-free software and its process, so the more free, the better. Freedom gives software security, stability, faster release cycles, more features, and fewer bugs. gNewSense is a 100% free distro, but to do that, they had to take out non-free drivers and firmware. Ubuntu has those drivers, but the downside is, if the drivers are faulty, nobody can fix them and you're fucked. With free drivers, there are usually fixes within a day of any major bug.

http://gnewsense.org
http://ubuntu.com

You're making a good choice, coming to Gnu/Linux. It'll be tough at first, as you'll be learning how to use a whole new operating system, but it'll start paying off fast.

Quote:
Originally Posted by Ub3rMonk3y
Would I be able to backup Windows XP just in case??
Yeah, you would.

This is a bit complex, and there are easier ways to do it, but the way I always back up my installed systems is just by directly imaging them with dd.

You'll want a command like this:

Code:
dd if=/dev/hda1 of=/media/disk/winxp_bak.img
What that means is it takes the input file /dev/hda1 and copies it to the oput file /media/disk/winxp_bak.img.

In that case, /dev/hda1 is the first IDE hard drive on the system. Adjust that for what your XP system's real device node is. The second partition on the first drive is /dev/hda2, while the second drive is /dev/hdb. This isn't too hard.

(On Ubuntu and some other later distros, it's /dev/sd<whatever> because of kernel hackery they use.)

The file that you just put on your backup drive (mounted at /media/disk) is a full image of the entire drive. You can copy it back to the drive later and have everything restored in one go if you need to.

Not all of us can run gNewSense (yet) and that includes myself (on some machines ), but the least he can do is try it and see if it works.
