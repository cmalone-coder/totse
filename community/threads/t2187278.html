Re: How to not only hide entire directories but also password protect them?
As this is an external drive, I would set the whole thing up as a Truecrypt volume, keep some bank documents or passwords or something in there, and then make a hidden Truecrypt volume inside that one (refer to the truecrypt docs as to how to do this).

The hidden volume will be undetectable to anyone else; if you are compelled to reveal the contents of the obviously encrypted volume, you can unlock the non-hidden one and show whoever it is your password files/illegally copied materials/taboo porn or whatever and keep the real secrets secret.

Truecrypt is fully cross-platform; while newer features usually hit Windows before they hit other OS's, it'll run on Windows, OS X, and GNU/Linux (I'm not sure about BSD's, but it might run there too). It's also free software, so it's likely trustable.
