Re: Usenet and IRC
Okay, so usenet lets people post small files in peices. So, they are encoded, and its becoming more common for them to be in yEnc. So, you download peices, according to the file names. Heres an example:

Cinema 3d XL incl. BodyPaint 3D v7.20 with good serials[13/13] - yEnc "Cinema4d XLplus.part18.rar" (1/1)

So, The post is Cinema 3D XL with Bodypaint 3d and serials. The second thing, which is [13/13] is the file number by the number of files he posted, so this would be the last file. Then it will say yEnc if it is yEnc encoded. Make sure your news client can decode yEnc encoding. Then the actual file name, and then the peice number over the total number of peices, being (1/1) because it is the last file in the set, so it is really small, meaning it didnt need to be broken into any peices. Now, depending on your client, hopefully for each file it will only display one post. In actuallity, there is a post for each part of the file. You just highlight all the posts with the thing you want in the title, and download it. The program should auto decode it and download it and all. It will usually be a bunch of rar files.

Now, for a couple more things before you start downloading. PAR files are parity files for incomplete posts, they are posted after the person posts all the posts, and some news servers didnt get all the files, so there are missing peices. There are tons of par tools out on the net, just look for them.

You can request files by making a post that say REQ: Whatever You Want. Newsgroup posters are great people, and will usually try to fill your requests. Be careful when you are downloading things though, because some posters request things in return for them posting something, so a post like this:

REQ : DriveImage 2002 ISO Full Version - Here is NeroMix 1.212- "NeroMIX.r04"yEnc (1/9)

Is actually NeroMix, the poster wants DriveImage 2002. People tend to fill the requests faster/more likely if you post something else.

Some things are posted over several days, and will be displayed like "day 1 of 3" or something similiar.

Okay, so those are the basics. Newsgroup downloads go fast as hell because your ISP is providing the news server to you. I downloaded GTA3 the day it was released, both CD's, in about 30 minutes.

If you have any questions, just post them in this thread.

And as for the news server, i believe it is netnews.attbi.com

I dont think they require you to log in either.
