For work, im running a whole bunch of calculations that spit out big output files. I am happy to grep and parse the data i need from them, but depending on how enthusiastic i get, there can be dozens of different directories holding these files. This usually means i need to run a command in every directory, which gets really old quickly.

Ive tried playing with for loops, but to no avail. Does anyone have any hints on how i would make a loop that runs a command in every sub directory (no need for recursive magic or anything, just what a simple "ls -d */" outputs).

Thanks for any help.

i came up with something like this:

#!/bin/bash

FILES=$(ls -d */)
for file in $FILES
do
grep whatever $file/*.out >> ~/file
done

that works assuming i have no spaces in directory names, which i don't do anyway (too annoying to type in).
