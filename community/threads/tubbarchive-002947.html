Collaboration
I had an idea. This is a group project. What happens is one person writes a chapter to a story. It can be in any format the writer would like; poetry, prose, ASCII, doesn't matter. You're chapter can even be broken into subchapters with subsubchapters if you'd like. When they are done, they pass it off to the next eprson who makes the next chapter however they would like.

  • Gorloche (ninjas.rule@gmail.com)

Rules:

  • You cannot make something already written invalid. It can be part of a dream sequence, it can be on television, but it can't just be flatly ignored.
  • You MUST give the file over to the first person who asks for it after you have finished.
  • If you do not add anything to it for a week, it gets sent to the next person. This is to keep things flowing.
  • If you miss your spot three times in a row, you're out of the list but can sign up again.
  • Anyone who signs up after it is started is added to the end of the list.


Also, make sure the file is a .doc. That's the one file everyoen can read.
