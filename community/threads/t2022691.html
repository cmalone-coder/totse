Re: Is there time enough to learn anything simple for July 4?
It depends a little upon how much space you have - if you have a large enough place to test things where you're not going to have the police called because a rocket de nozzled itself loudly, then you're probably fine if you can find sources of chems.

If this is your first firework, I would recommend a fountain. Start by following a tutorial, stay safe, and start small. On the night if you can be bothered, making a bloody huge one always looks more impressive than a class C store bought one.

Salutes, although easy, require you to work with some stronger oxidisers and more finely divided metals. Also German dark aluminium can be incredibly expensive. Smoke bombs are frankly a little boring, especially at night, and appear to me to be (along with peroxides) the greatest source of accidents.
