We are experiencing technical difficulties. Do not adjust your set.
totse's server's operating system ran out of allocatable file handles. Since each new UBB thread modifies a file (the forum header) and creates a file (messages in the thread) what would happen is that the header would get updated but the thread file would be created as a zero-byte file.

I had to reboot the server to clear the problem, then restore backups of Spurious Generalties and Half Baked from 48 hours ago, then delete all of the zero-byte files and run a bunch of UBB cleanup routines. The Spurious Generalities and Half Baked forums are back on-line now.

I also switched flood control back to 61 seconds.
