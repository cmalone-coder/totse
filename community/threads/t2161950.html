Re: So I think I'm hardcore enough to start with Slackware...
Most Slackware documentation is outdated.
One thing newbies generaly fails to understand is Slackware comes with many different pre-compiled kernels, you need to choose among those which fits better with your machine; or compile another yourself.
Slackware has no package management, it is a real pain.

Slackware used to be a great learning tool, but it seriously lack uptodate documentation.
Unless you have an old computer, i advise you go with either Gentoo or Arch Linux instead.
If what you really want is a slackware like, but more uptodate system, go with Zenwalk.

As for the Window/Desktop Manager, Xfce is great, it's not cryptic like Fluxbox, and lightweight.
But really a Window Manager is more a matter of personal preference, try them all, see which one you prefer.

I skimmed through the guide you found, it's more about general Unix basics. I doubt you will have any problems installing, just read the annoncment carefully:
http://slackware.com/announce/12.1.php

Re: So I think I'm hardcore enough to start with Slackware...
So so so, you decided to become a man, welcome then!

First of all, don't be afraid of people say about slackware being too user-unfriendly, it's simply too traditional, you'll find it more different than the more mainstream distros, but very customizable, to an amazing degree.

Installation is easy, but I recommend you get the DVD rather than anything else.

Once you install it, you'll end up with a command-line, unlike virtually other distros, it won't boot up GDM or some shit like that, it'll just start with a good ol' Unix console. Log in and type startx.

If you want to change your window manager type wmconfig.

If you want GNOME (it doesn't come by default with Slackware), try this http://gnomeslackbuild.org/ or google dropline.

Installing shit is usually done in two ways: Download a .tgz package and run "installpkg package.tgz" on it, or compile it from source.

Or you could get something like slapt or some shit and have a more debian-like installer, I do not recommend this.

Either ways, don't listen to what anyone says about it, just try it yourself and see what happens, good luck
