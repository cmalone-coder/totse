Re: how do i cure AIDs?
Well AIDS is just a syndrome that results from HIV. So really you need to eradicate HIV to cure AIDS. The best way to eradicate a virus? Inoculation! How do we inoculate people against HIV? A vaccine! Where do we get this vaccine? We would have to make it.

Commonly, you do this by taking a sample of the virus, attenuating or killing it, and then sticking it in someone so their immune system can create antibodies for it. That way, if a live, dangerous version of the virus ever infects them (in the case of HIV: gay sechs), their body instantly recognizes and kills it.

The reason we've sucked giant dick at doing this for HIV so far is that:



It's extremely prone to mutation and,
The part of the virus that the immune system needs to recognize (the epitope) varies too widely.

My solution to this problem is to genetically engineer a new version of HIV to do two things: compete with the old version for infective control of the host (the new version would obviously be designed to, you know, win), and infect the host cell through a known and replicable cellular receptor. Once the new HIV has replaced the old HIV in the host, we then synthesize an agent that mimics the cellular receptor it binds with, and treat the patient with that. The new (and only present) HIV starts binding with the agent instead of the host cell, is unable to replicate, and tada - dies off.

Looks like I beat you to it, OP.

The problem with your AIDS is that it would have to stop the original AIDS (which we'll call GRIDS to prevent confusion) from infecting any cells instead of cohabitating with it. The only way that would work is if it either destroyed all the host cells before GRIDS did, meaning you didn't have GRIDS prior to getting AIDS, in which case you've just infected yourself with a lethal virus for no reason; or if it actively attacked GRIDS so there would only be AIDS. The problem is that both viruses are subject to mutation. All you would likely end up doing is creating 2 mutant viruses that both destroy the host immune system and resist countermeasures.

Protease inhibitors actually work better than what you've proposed because they block the GRIDS virus from being able to jack into a host cell altogether, although GRIDS has evolved around this as well. It's a biological arms race and we're always at a disadvantage.
