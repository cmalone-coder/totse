I'm surprised you're having no problems with vista, that's a first.

Yea i would go with ubuntu as it's very noob friendly and has great support. There are loads of communities out there which offer a lot of help when getting started. There are also a number of books written for ubuntu Linux, you might want to check them out.

There is a more up to date version available for download, so you probably should go with that.

http://ubuntuforums.org/ is good. There are also quite a few IRC rooms around, you might even find ones specific to your country.

Beginning Ubuntu Linux: From Novice to Professional book published by Apress is really good, so you might wonna get an electronic version of it, or possibly buy it, if that's your thing.

Normally with ubuntu everything work right of the box, but you might have some minor issues now and again, but nothing that shouldn't be too difficult to solve.
