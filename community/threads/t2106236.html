Re: PHP script not executing fully
"Undefined offset" means the key you tried doesn't exist in the array.

For example, if I did:

Code:
$var = array ();

for ($i = 0; $i < 10; ++$i)
{
    echo $var[$i];
}

I would get:

Code:
Notice: Undefined offset: 0 in __FILE__ on __LINE__
Notice: Undefined offset: 1 in __FILE__ on __LINE__
...
Notice: Undefined offset: 9 in __FILE__ on __LINE__
Notice: Undefined offset: 10 in __FILE__ on __LINE__
To debug, have a look at what's in the array by passing it to print_r () .
