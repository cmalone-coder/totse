However, executing the batch file on a server machine is not quite as trivial as it may sound. If you place the batch file on the server (in a share for instance) and run it from your workstation, it will execute the commands ON YOUR WORKSTATION, not the server. Thus effectively stopping network services on your machine if you have sufficient rights to do so.

You need to be remote admin-ing the server through any available means... and that as well, is not trivial. And on top of that, you need rights ON THE SERVER to administratively take down the network interfaces, not just any user is "allowed" to do that. A domain administrator account would be sufficient for this task in NT but it gets more complex in 2000 with ADS.

Its not just as easy as running a batch file, if it was, script kiddies would rule the world. Thank lucifer, they don't.
