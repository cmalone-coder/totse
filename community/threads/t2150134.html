Yeah Slackware hardly requires any ram. Its kinda hard to install because theres no GUI installer so read a tutorial on installing it first. I tried to install it but I couldn't figure out how to use the command line partitioner. Why not get a new ram card though? You can get a 2GB ram card for about $50.

The partitioner Slackware uses is just fdisk. It comes with all linux distro's I think. First thing you should do is type fdisk -l and it will list all the partitions on your harddrive so you'll know whats what. Heres my harddrive
