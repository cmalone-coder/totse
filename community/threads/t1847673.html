I'll second that especially if it revs high before shifting. You will find this cable on the throttle lever near the throttle body. There may be several cabless here. You are looking for the one that goes to the trans. It will have a button that takes some pressure to move. When you press the button, push the cable towards the button, make only small adjustments - like about 1/8" at a time. This will lower the line pressure to the clutches and can cause you to burn up the trans if the adjustment is not done properly - If the trans starts shifting way early and or slipping into gear set it back!

It is possible that when the rebuild was done the builder modified the valve body to make the unit shift harder.
