Re: Linux
ls /dev
*this is a list of devices, pick your cdrom and remember the name
ls /mnt
*this is a list of your mount points, pick an apropraite point for mounting an audio cd. otherwise create a folder by
cd /mnt/
mkdir cdrom
*now your mount folder is cdrom
su your_root_password
*now your logged in as root so dont delete anything
mount /dev/name_of_cdrom_device /mnt/cdrom
*you have just mounted a cdrom, natalus should open showing the contents, if not dont worry its still mounted.
*go do your thing with xmms
*be sure to log out of the su mode since that is equivelent to root and you can damage things running as a su or root.

i hope that helped let me know if your still having problems. alternatly you can
cat /mnt/ > /home/mnt.txt
cat /dev/ > /home/dev.txt
and post them so we can give the exact commands. hoped that helped. the documentation on the mandrake users organization web site is excelent. also i use a que book called practical linux.

Re: Linux
well you have two feasible options for installing linux. the most common is just taking your hard drive(s) and making a windows partition then dividing the rest amongst ext2 partitions for linux.

the less common but clearly superior method is vmware which allows you to run windows inside of a linux window. this is a bit more advanced and i would hold off on it unless some one you know can set it up for you.


as for the terminals, i think your talking about shells (bash, ash, etc), they all do the same basic things but each have thier own strengths and weaknesses. bash is certainly the best in my opinion. a shell like ash is usefull becasue its much simpler and smaller than bash so it can be used in a floppy distro. there are a lot of shells to play with but in the end you will most likely go back to bash.

if you want to try hacking via the shell then go to hackerslab.org and signup. thye give you a shell via telnet so it can be accessed through windows.

quote:
BTW, whats up iwth tehre being like 6 terminals?)


Having six virtual terminals, accessable by pressing alt+(1-6), is handy if you like doing more than one thing at a time, reading a text file, writing a text file, where you need to do one thing without closing the other. It also becomes useful when a program crashes, you can flip over to another terminal and kill it from there.
