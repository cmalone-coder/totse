Replacement for UBB
I've been working on getting a replacement for UBB set up here for the past few weeks and things are coming together. I've installed a separate database server to handle the message database and I went and bought a copy of vBulletin. Right now I'm working on porting the UBB data over to vBulletin on a test server. The version of UBB that totse uses is so old that there are no ready-made conversion tools around, so I've had to take a UBB converter for a more recent version of UBB and adapt it.

One thing I've found is that vBulletin in particular and PHP in general are both pretty hostile to non-ASCII non-UTF-8 characters, which means that any posts using non-ASCII non-UTF-8 characters won't get ported over.

Also, starting immediately, user names with non-ASCII non-UTF-8 characters are going to get shit-canned.

So if you're using a character or characters in your handle that aren't on a standard US keyboard, or if you're using a character that's typically used in programming (such as a pipe or brackets), your account will probably disappear real soon. It's nothing personal, feel free to re-register, but don't use non-ASCII non-UTF-8 characters or your account will just get shit-canned again.

Based on my schedule the conversion and setup may take a few more weeks, but I expect to have everything done by the end of the year.
