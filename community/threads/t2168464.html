The linux Asus EeePC's default OS is Xandros which is a fork of Debian. As you can imagine, because of this - there is a huge Debian community using the EeePC with plenty of wiki articles. Currently I'm still using Xandros with the Advanced Desktop Option (kde) but as Debian is my distro of choice on many of my computers at home - this Christmas I'm going to be putting DebianEeePC on both mine and my mums EeePC.

But the EeePC's are just computers man, if you don't like Xandros or Debian for that matter then you can just install another OS...

http://wiki.debian.org/DebianEeePC

I'll write up a guide when I do my install so you can see if it's for you...
