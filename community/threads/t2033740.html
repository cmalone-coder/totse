Ahh, very good point - almost. IP addresses can change but I guess it would be possible for the police to trace it via MAC address. This is a unique address assigned to every piece of networking hardware and in theory it would be possible, albeit very diffcult to trace a computer this way.

However, you can change the MAC address of most hardware.

LoJack can't be installed into the BIOS. No software can be embedded at that level - and if it was, it would be useless as there is nothing to drive it.
