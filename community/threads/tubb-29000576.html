Re: Are DEs any good?
quote:
I've also heard if you get the Mark XIX frame, you can just slap on a different barrel system and clip and change calibres.


To some extent. For example,

Generally 9MM can fit into a .40S&W magazines and function flawlessly. (feedlips, follower, etc is pretty much the same).

.357SIG will work in .40S&W mags and vice versa.

.357SIG only requires a drop in barrel if you have the gun already chambered in the .40S&W since the case is simular in charecteristics except it's bottlenecked for the .355 bullet.

Therefore the factory extractor, ejector, etc. would function flawlessly between the two calibers.

.45's can take the .400corbon drop in barrel since the .400 is a bottlenecked .45

It really depends man. Honestly the only coverision i'd suggest is a .40S&W to .357SIG both are really impressive rounds.
