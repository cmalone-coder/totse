Re: Glock Safeties
For all practical purposes, the only way a Glock is going to fire is if the trigger gets pulled. I know it seems like that's how it is on all guns, but there's alot that will fire if dropped.

On the down side though, if a retention strap of a holster gets in the way, it will go off. If a careless shooter leaves his finger in the trigger guard while holstering, it will go off. If you have a holster that pinches the gun at the trigger guard, then there's a chance it will go off.

There's alot of people that complain about the apparent lack of a safety. However if you're cautious like you should be around ALL firearms, then there shouldn't be any problem.

I have no problem with Glocks. They are extremely reliable and I don't recall seeing one get jammed up. I just can't shoot them worth a shit, so I don't mess with them.

Re: Glock Safeties
Series 80 styles have a firing pin block. There's not very many that are like that though. The majority don't have it because the design makes the trigger pull a little bit rough. Almost all have the half cock notch, but it's far from being safe. A small bump could still drop the hammer if it's at half cock.

Either way, the safety is still a shitload faster than trying to pull the hammer back. The main spring is very strong, so the wear isn't oo big of an issue. If a condition 1 weapon makes you nervous than you don't really have any reason to be around them. It don't go boom unless you pull the trigger, so carry it like it was meant to be.
