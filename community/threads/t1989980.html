Re: Switching barcodes, and doing it right.
Essentially.

UPC bar codes are both human and machine readable. The bars tell the machine the same number as is printed underneath. That way, if the scanner isn't working the cashier can just type in the code.

If you want to wind up with a valid bar code you'll have to copy another item in that store. All you need to do is write down the numbers below the bar code, enter those into your label making software, and go nuts.

Actual piece of useful information:

At Target, when the original bar code is damaged or gone, someone with a portable printer (usually fitting room) can print up a new one that honestly looks ghetto-fied. The label printer mentioned earlier could probably print it, I will try and grab a picture next time I see one of these.

To get teh number (called a DPCI at target, stands for department, class, item) a team member has to find the same item elsewhere and scan the bar code of it with the PDA or look on the price label on the shelf for the DPCI. (doing this for more than 2 items is a shit job) Then a portable printer is found and the new bar code is printed. Its about an inch by 1.25 inches in size and has a bar code readable only by the checkouts and the DPCI number below it.

The DPCI is different from the UPC. Most other stores (Wal Mart, etc.) will have a similar system
