Unless you are using some variant of unix, you will probably find that in the long run it is less trouble to buy a wireless router. Windows router programs and firewalls can be unstable in some configurations and depending on your system speed can be a real drain. I don't trust wireless encryption but my router cost only $20 more than the switch that's built into it. Lots of features too.

In addition, bluetooth can be rather inadequate. You would probably get much more enjoyment out of 802.11b (WiFi) or 802.11g (better than 802.11b).

A wireless router is a much better idea than Bluetooth.



However, allow me to warn you: learn how to secure a wifi network. Businesses who run weak-ass security over networks are my best customers (I'm a consultant), because I can show them how stinking easy it is to break into their networks.



Make sure you disable SSID broadcasting. Use 128-bit encryption. If the router allows it, disable remote administration (meaning from the internet). Use MAC address filtering. And finally, if you can manage to figure it out, the most important thing to use is VPN over the network.



If you do that, then your network will be secure enough that wifi-hackers won't bother trying, and will go find the idiot who runs their Linksys network with no WEP and all defaults (yes, it happens... a lot). Also, having the NAT inside the router between you and the intarweb is always a good idea.
