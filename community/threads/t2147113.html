Pidgin is installed by default. Applications>Internet>Pidgin.

Install the SWFdec plugin if you want youtube to work, install Gnash if you want flash in general to work. SWFdec focuses mostly on youtube at the cost of other types of flash. You can install then via the bar that pops down in Firefox when you go to a page with flash.

(You are using Ubuntu, right? I'm assuming you are.)

Pidgin handles MSN. OpenOffice (also installed by default) handles documents. Totem (also installed by default) handles movies, but if it doesn't have a codec, it'll prompt you to install it. Just check the box and hit apply if/when that comes up. Rhythmbox is the music player installed by default, and it's the one I use.
