I have a dv9500, and it has a scanner that I got working mostly with stuff from the repo and a few other things that I had to build and install manually (read: "./configure && make && sudo make install"). While you will have to put in a username, you can use your fingerprint instead of the password (though I highly recommend leaving a way for you to get into your computer without it, because the PAM module for fingerprint ID on that isn't quite mature yet).

If the dv2k is the same as mine (or also supported by libfprint) you can get the information needed to set it up libfprint. To find out model you have, try running "lsusb" (in terminal). My model is an Authentec, and uses a driver that's in the Ubuntu repos (aes2505 or something like that, I don't have the laptop on hand to check now), so if you have that too, you'll probably be good.

Also, looking at the libfprint wiki for the first time in quite a few months, I'm very pleasantly surprised at how much the project seems to have matured. Setting this up will probably be fun and lucrative in the end. Have fun with it and tell us how it goes.
