Re: What to use TruCrypt for? And hiding your stuff
Well truecrypt offers many options, not just to create a file container volume but also to encrypt non-system partitions like external devices such as USB sticks,..etc. I believe there are two ways of doing so. You can create a file container volume on that USB stick and encrypt that volume or you can just encrypt the device itself.

Also, if you want to create a volume on your computer, you have the options of creating it has a standard file container or a hidden file container. The hidden container is good encase your computer gets confiscated by the police department. You also have the option to rename the file extension of that encrypted volume to something such .img, .dat, .iso. So itself looks like it has nothing to do with truecrypt. Also, once encrypted, there is no way of knowing that volume is associated with truecrypt, because truecrypt does not apply any kinda ID or signature to the volume.

I think there are also options to encrypt your entire file system partition, but I'm not sure if that feature is still supported, as i believe there were some kind of complications and difficulties surrounding that.

Concerning the content that you should encrypt , well anything that is deemed to be copyrighted I guess. Also if you feel like you need to encrypt pictures you have on your computer, then one can only wonder what the hell you're looking at.

Re: What to use TruCrypt for? And hiding your stuff
Quote:
Originally Posted by zeusy
Then, what is the the best crypto tool for GNU/BSD?
dm-crypt and LUKS for Linux-based systems, and whatever tools are there for your BSD (I don't really know that much about the BSD's, so I'm not the one to ask here). Truecrypt is mainly a windows app.

Gnu is too broad to talk about, because crypto is usually implemented in the kernel to choke as much speed out of it as possible. For instance, twofish and AES are implemented in assembly for x86 and x86_64 in Linux.

If you're running Linux, it's nearly trivial to set up FDE. Truecrypt can be used on top of that to provide deniable encryption, and it's always good to have this in case you're forced to reveal the key for your FDE. EncFS is also good for this if you don't want to use Truecrypt, though that isn't very deniable.

Any discussion about Truecrypt inevitably comes back to the deniable crypto. That's the one thing Truecrypt has that nothing else does, and it's incredibly awesome. You should always store what needs to be secure against yourself in a hidden volume, because anywhere else doesn't really cut it.
