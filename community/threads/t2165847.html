See, up until the last part, I'd call the system 'GNU' or 'Gnu', referring to the OS that Richard Stallman started in the 80's. That OS was always intended to include things written by people other than the GNU Project staff proper, specifically, any free software. TeX was the first of these (since it predates the GNU Project).

Gnu is a collective term. It doesn't refer to any executable or library, it refers to the collection of executables and libraries and other things which make up an OS. But Gnu only includes free software properly, so you'd be using a modified, non-free Gnu system.
