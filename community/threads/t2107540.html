There's probably another profile used for su-type logins. I know bash uses .bashrc as well as .bash_profile, and normally only one of those is run when you use su whereas both are run if you log in normally (though I don't remember which offhand).

You could always use the source command to run the login script though, as follows (assuming the .profile is in your home directory):

source ~/.profile
