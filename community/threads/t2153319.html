Follow the instructions for the Kylix library which are:
unpack the files,
They are packed using tar/gunzip.
You can read the tar manual, `man tar`
Use your favorite archive manager or:
Kylix: tar -xvf <path>.-C /tmp/Kylixlib
HJ: tar -xvf <path> -C ~/.
Gnu/Linux is case sensitive.
Get a prompt, get root ( use `su`, or sudo bash if you are using Ubuntu ), then type /tmp/Kylixlib/*/install.sh.
If you get any errors along the lines of, permission denied, you forgot to use the su command.
Once you are done installing the kylix library and unpacking HJ, use ./HJSplittLX in your home directory to execute it.
If you can't get it to work, you could simply use the dos version with dosemu. Or, use wine/cedega.
