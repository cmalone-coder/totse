Oddly, in my travels I haven't been able to find a thing about three-part-staves except for random anim� and movie sites detailing the armament of some character or another.

Regardless, a three-part-staff is a set of three two foot long rods bund together with chains or ropes. Think of it as a giant set of nunchucks with an extra chuck and you'll get the idea.

Mine is rather smaller than standard, with each segment being only 15 inches long. This is so I have some remote chance of concealing the staff.

Three-part-staves are effective for two major reasons: First off, the double hinge design allows the user to get a lot of leverage behind each hit. The mechanics are rather like a set of nunchucks with an extra pivot, and the centrifugal force from swinging the staff around puts a lot of power behind each blow. Second up is the sheer versatility of the staff - You can use it to entagle the enemy, weild it like a pair of nunchucks, use it like a staff, or a linked set of escrima sticks.
