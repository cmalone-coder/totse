You may have to add some additional options to the boot sequence for it to load properly.

Actually, I think in ubuntu it easier because it provides certain options on the boot menu to solve this problem. To solve it in ubuntu, select f6 for "other options"..and check all of these options "acpi = off" "noapic" and "nolapic" , a little asterisk will appear next to the selected option.

It'll work fine then, but you may have to add these options to the grub menu.list, so you don't have to keep adding them in every time.

Also, after you have installed, you may not have the f6 option and it might just try to load and then hang. If this happens do this.

When booting from the harddisk quickly press esc to enter the menu. Then select ubuntu section and press e to edit, then select the second kernel recovery and press e to edit.

and add these to the end of the boot sequence line "acpi = off" "noapic" and "nolapic" without the quotes.

Then it'll boot perfectly fine. You will want to add those options to /boot/grub/menu.list where it says "# defoptions" and "# altoptions"

Once you're in, start a terminal window and type this.

This will back up your original grub/menu.lst

Code:
sudo cp /boot/grub/menu.lst /boot/grub/menu.lst.backup
This will open up grub/menu/lst in a text editor , so you can make the changes.

Code:
gksudo gedit /boot/grub/menu.lst
This just updates it after your done.
Code:
sudo update-grub

I'm not sure how about doing it in fedora, as I haven't really used it. But I'm assuming it'll be pretty much be the same thing, and might even provide similar boot options.

Post back, to lets us know how you're getting along.
