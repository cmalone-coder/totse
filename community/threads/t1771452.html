Well, all the comps at my local Vo-Tech use DeepFreeze, and I gleaned from the teacher how it works. Here goes:

When DeepFreeze is installed, the program creates an image of the hard drive, which is stored somewhere, directory I guess. WHAT DEEPFREEZE ACTUALLY IS:

DeepFreeze keeps a backup of the FAT table and steers any changes away from inhabited sectors. It then only lets windows modify the backup so that the original stays untouched. There is no other partition and program can touch this.

Format works by wiping the FAT table which in this case is only a copy.

HOW TO STOP IT:

1. Get a boot disk or boot CD

2. Get into a DOS prompt

I will assume the default directories.

3. Delete the deepfreeze files in the root directory (every .exe and .com except command.com)

4. Delete the deepfreeze folder inside the program files folder. (it may or may not be inside a folder names byper technologies)

5. Reboot and don't let anybody find out.

NOTE: You may have to crack the BIOS password or reset it to get the system to boot off of a disk or CD.
