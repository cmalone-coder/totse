Re: Stealing/Making lookalike license plates
Find someone with a machine press and engineering skill (a mechanic/metal engineer). They can easily do it.

Find someone with a bench, sheetmetal, a hard rectangular prism shaped object and a hammer.

Print off a copy of the number plate. Cut out the numbers and letters. Trace them onto the sheetmetal. The hard rectangular object must be the same width as the lettering. Place the object under a straight part of a letter. Grab the hammer and bang the sheetmetal around that part of the letter to make a large indent. Move the rectangular object around to another part of the letter and bang it with a hammer. Repeat.

Corners can be done by finding/creating an object with the same radius. Otherwise use the straight piece and move it every few hits to create the curved parts of the numbers or letters.

If you stuff up it doesn't really matter because sheetmetal is cheap.

In theory these homemade plates should be indistinguishable from the real thing when it is on a vehicle.
