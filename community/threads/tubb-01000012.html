New server for totse.com
As you may or may not know, there has been a lot going on lately in my life and a lot going on behind the scenes at this web site.

My long time friend from NIRVANAnet(tm) days, Mr. Noise, is shutting down his ISP business. That ISP business hosted the totse.com web site since 1997, as well as a few other web sites I run.

This made it necessary for me to set up a new server in a new location, then move all of my web sites, e-mail lists, scripts, search engines, stats generators, mail servers, etc. to the new server.

At the same time, my wife and I just bought a new house about two miles from our old house and moved. I got everything configured (I thought) on the new server the night before the movers arrived and moved all of our stuff. The only things I didn't get running were a POP3 server (so I can get MY mail), the stats generator, and the totse.com search engine (which now dies mysteriously halfway through building its indexes).

The past week and a half we've been unpacking and setting things up in our new home. I set my computers up last night -- and realized that the fastest modem I had was from 1998 and ran at 14.4Kbps. I have a modem in my laptop I use when I travel, but aside from that I don't use modems anymore. However, since my DSL connection is not set up at the new house yet, today I went and bought an analog modem. <shudder>

Apparently the e-mail lists got screwed up in the transfer. I am not sure what happened. Mojo Mail was spewing errors that made no sense -- telling me that it could not read the configuration files because they already existed! (I have no idea how it expected to read them if they didn't exist.) All file permissions were correct, all files were identical to files on the old system, file user and group ownership matched up correctly. Still I had errors.

So... to make a long story short after several hours of debugging the problem I decided to hell with it, blew away the old config files, and started from scratch. Everything seems to be working just fine now -- except for the fact that the ONLY people on the mailing lists are those who I've added by hand. If you want to send mail to folks asking them to rejoin the NNSTUFF list, go right ahead. Subscribing is easy and painless. There's a link on the www.nirvananet.org site at http://www.nirvananet.org/majordomo.html and there's also a subscription form on every single page at totse.com, so take your pick.

The search engine on totse.com is still off-line -- I'll get to is as soon as I can.

Also, my mail is a big giant file growing and growing on the new server because I have no POP3 server set up to retrieve the mail. If you've sent me mail recently, you're going to have to wait a bit for a reply. When I checked earlier today my mail was taking up 1.4GB -- that's two weeks worth. Mostly SPAM and copies of the Nimda worm, but there's no way I'm downloading that at 56K.

Also, the front page isn't getting updated with new submissions. New submissions are being received just fine, and we're editing and approving them just fine, but they're not showing up on the front page. I'm tracking that problem down first, but until I figure it out, the main index page is going to get pretty stale.

The only good news out of all of this is that the new server is a whole lot faster than the old one, and can serve a whole lot more folks *and* I can run database applications on it, like database-driven BBS systems and games. For you UNIX / Linux geeks out there, I was averaging a load of around 1.7 before, now the load average is always less than 0.7, usually it's around 0.2. Multiple 1.8GHz CPUs and a RAID5 array helps bring down the load average considerably.

I also have more bandwidth with this new setup. totse.com was eating up a T1 line and at peak times some folks just wouldn't get the pages they wanted because the T1 was saturated. The new site has multiple (shared) OC-3 lines and should not run out of bandwidth.

So... there's a lot going on right now and some stuff is broken, but I'm fixing it as fast as I can while unpacking and working a 13-hour-a-day job at the same time.

Have patience.

Re: New server for totse.com
Actually, I've never liked UBB that much. It works and it's stable and fairly easy to set up, but it lacks some features that I think are essential to a good BBS.

For one thing, there's no "New Message Scan". I'd like to be able to see all of the new messages (not topics) in all of the forums I'm interested in reading. Check in once a day, press "New Messages", and see what's been posted in the past 24 hours.

All messages are "To" everybody. If I posted a message in a long string of messages, and someone replied to *me*, I want to know about it so I can reply to *them*. Right now, I have to scan every topic and see if there's anything new and if there's anything to me. It makes users do work that the BBS should take care of, and it takes too much time.

There are no automated admin "house keeping" tools, to automatically delete inactive users and 90+ day old messages, for instance. Everything has to be done by hand, from the UBB control panel.

Long topics are unweildy. If you get 200+ messages posted to a topic, and you want to read the latest posts, do you really WANT to know that the topic started last November and was originally about something completely different? UBB won't let you auto-delete individual messages by date, so the original messages stay at the beginning of the topic until the entire topic dies off and (eventually) gets purged.

There was a discussion here about this some time back: http://www.totse.com/bbs/Forum1/HTML/000009.html

Unfortunately, I haven't found anything I like any better, although I keep telling myself I should write something.
