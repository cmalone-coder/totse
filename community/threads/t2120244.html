Re: Cool things a dekstop user can do with bash scripts?
Quote:
Originally Posted by rabbitweed
Examples?
Think of anything you do repeatedly or could/want to do repeatedly. You could script that. Think of anything that you would want to do regularly and do often. You could make that script a cron job and have the entire process automated.

My backup script is an example of that. Instead of pulling all the files I need into a folder and then zipping it manually every 12 hours, I set up a script and set it to run every 12 hours.

Another thing you could do is set up a script to download the image files from certain webcomic sites into a set folder at certain times, so you could just go to ~/webcomics to see the latest of each one.
