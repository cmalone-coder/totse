First off, your title is inappropriate. If you were asking about help with Linux, it'd be fine, but you're asking for help with Gnu(/Linux). Gnu (or Gnu/Linux) is an operating system, Linux is a kernel. If you told us which distribution of Gnu/Linux you were using, that'd be even better and more specific. You seem to be using Ubuntu (or maybe Debian, I don't know if they have synaptic as well).

So now that we're on slightly more stable ground, let's look at this: Do you really need to use those programs? If the movie doesn't work in Totem or VLC, you won't be able to uncompress it and burn it to a disc anyways. Have you tried installing the codecs for whatever format it is? Ubuntu includes most of these in the Multiverse repository, search for "gstreamer" in synaptic and install some of the plugins, if the right one is there.
