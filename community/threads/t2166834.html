My first Mac
I've been tinkering around with PCs ever since my dad had a computer. Our first computer was simply run from MS-DOS and you'd simply type the program in to play the game, make the spreadsheet, etc. and I've been a PC man ever since. I've bought multiple laptops running xp as well as vista and I decided it was time for a change. I now own a dual 2.5 gig Macbook Pro (17 inch screen) and besides the occasional problem regarding a program that's not responding I really could not be happier with this product. I believe that it would be a much easier world if everything were based upon Mac OS X and I don't know why windows is so popular now that I'm a regular Mac user. I just wanted to say you guys got it right and there is no way I'm gonna run windows again... unless it's on bootcamp.

Stay safe,
Bos
