Re: Worst virus/destructive/spyware program experience ever
Back before I learned how to write rootkits, my friend and I had "virus wars" with each other...

I wrote one that was designed to embed itself in any and all running programs that it could acquire a new thread context in, and then communicate with itself (to keep it going) while cancelling any and all Windows shutdowns (minus, of course, a cold boot or reset) and disabling access to regedit and the command line. Task Manager could still run, but it didn't matter... Not only were there two copies of the virus engine running at once, if either one of them got terminated, the other would start a new one and take over for the old one. If somehow BOTH engines were terminated, one of the hijacked programs currently running would simply restart them.

Little did I know that I coded a key part wrong...

One of the rules we had in this little war was to create countermeasures to our own code in order for a quick and speedy recovery. I did this before I even wrote the original virus code. However, what I didn't realize at the time was that I used the wrong registry setting... and disallowed access to EVERY program with the exception of explorer and the task manager. No notepad, no failsafe, no command line, no ANYTHING of use. I couldn't shut down the virus and I had lost all use of my computer.

So how did I solve it?

Luckily, I wrote the failsafe program "wrong" as well, so if I could figure out a way to get the failsafe program to run, everything would be fixed. So I renamed my failsafe program to taskman.exe, renamed taskman.exe to taskman.bak, copied the failsafe to the Windows folder, and pressed Ctrl+Shift+Esc. This is NOT an easy task to perform... because Windows notices if taskman.exe has been deleted, renamed, or changed, and it will automatically copy a valid version of taskman.exe to the Windows folder. So the trick was to be as quick as possible (before Windows noticed what was going on)

Definitely a day filled with headaches.
