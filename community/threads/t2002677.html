Re: X Window issue
I do not agree with your method of just posting what YOU think is relevant. In any case, since you don't think the whole file is relevant, I will just tell you what you should do:

Add a Section "Device" for your nVidia card.
Make sure both sections for the Intel graphics card which uses the i810 driver has a specific BusID setting, and do this also for the nVidia card.

The specific BusID can be retrieved using "lspci", if you don't have that installed, search for it in your distribution's repository and install it.

For Fedora, "lspci" is in package "pciutils".. so "yum install pciutils" would install it, and it would be in /sbin/ as /sbin/lspci.

Likewise in the /etc/X11/xorg.conf file you will need to modify your ServerLayout section to use either the Intel video card, or the nVidia card, or both, if you choose both, make sure to add a Section "Monitor" for the secondary card also and associate the two properly.
