Re: Running PHP Scripts with e107
the reason it's not showing you any errors is because you don't have a mysql_error() function in there.

Lesee...

if you add this if statement underneath where you assign the variable $result, you should get an error output;

Code:
if (!$result)

{

die(mysql_error());

}
You could also use a while statement to print all results from the database, like so:

Code:
$query=mysql_query("SELECT * FROM chems ORDER BY simple_name");

while ($row=mysql_fetch_array($query))

	{

	echo " <tr>\n";

echo " <td><a class=\"vari_link\" href=\"?get=chemistry&page=chemicals&chemical=$che mical\">$simple_name</a></td>\n";

echo " <td><a class=\"vari_link\" href=\"?get=chemistry&page=chemicals&chemical=$che mical\">$chem_name</a></td>\n";

echo " <td><a class=\"vari_link\" href=\"?get=chemistry&page=chemicals&chemical_fami ly=$c_family\">$chem_family</td>\n";

echo " </tr>\n";

	}
You will however, need to take out the php variables you have defined in the section where you echo all of the info, you can replace them with (using my above example):

Code:
$row['chemical']
Instead of the variable $chemical. That corresponds to the name of the row in your database, so if it isn't named chemical, then you need to use that name in the above code.

Any questions?
