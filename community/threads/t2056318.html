Opinions and Ideas - Also some Rules
I'm going to preface this by saying that these rules are here to help the forum users; if you find them too overbearing and stifling, please post in this thread. These are not rules that I intend to set without the blessing of the forum.
  • No begging for money. This isn't SG, HB, or B&M; that means, if I catch you making worthless posts that beg for money and have no content it will be constituted as spam and you will receive a 10-day ban. Sorry to be so harsh on this one but I want to clean this forum up and give it the love it deserves. Post your bullshit threads in one of the other forums.
  • No scams. There is an infraction 'cause' that fits scams perfectly; it's against totse rules so don't do it. Take it to Bad Ideas, if you must, and it may be tolerated there. It will not be tolerated here. This forum is for discussion of real money and real ways to make money, not theft.
  • If you post a referral link, post a generic link as well. This should go without saying. Personally, I'm of the opinion that we should have a subforum for making money online. I think the main forum should be reserved for discussion of real-world ways to make significant amounts of money. We can discuss that in this thread.

That is all I've got off the top of my head. I'd really appreciate it if everyone would read and respond to these. If you think they need changed or added to, let me know by posting here. This forum is a group effort and I want to include everyone. Thanks.
