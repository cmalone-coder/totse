*Note - If the pictures aren't working for anyone, open a new browser window and cut and paste the links into the address bar in order to see them. (Thanks to geocities anti-remote linking)



Nice pictures. Thanks for showing us your handywork. The only suggestion I would have is if you're using a slower burning composition like whistle mix in a pipe bomb, use threaded endcaps. For slower burning compositions threaded caps beat anything you could glue on hands down. Also, put your fuse in the SIDE of the pipe instead of through the end, like ICP said that way the powder will burn in two different directions at the same time, so the gas release is twice as fast.

Oh yeah, and if you want to post your pictures from geocities as regular images instead of links, change the file extension of the image from .jpg to .txt and post it like you would any other image. It works, trust me. Most all browsers recognize the file as an image file and they display it as such, but since geocites thinks it's a textfile, they don't block the remote linking of it.

(You might also want to downsize them a bit or issue a warning that the thread contains large images before doing that.)
