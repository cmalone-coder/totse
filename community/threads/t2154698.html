The box with 4 gigs almost certainly isn't a hardware/software issue. You can't expect to see all 4 gigs on most 32-bit systems because you only get 32-bits of addressable virtual memory, only some of which will map to RAM. Actually chip support is commonly 36-bit now-a-days even when running in 32-bit mode and I think you can compile a kernel with support for PAE and see all 4 gigs, but most kernels don't compile with this by default to keep support for legacy processors (really fucking stupid...legacy meaning before pentium pros).

Your other box most likely has fucked up RAM or slots or something.

The answer was to use a different x86 kernel.

Kernel 2.6.25-2-486 didn't allow me to see 2GB RAM.
However, Linux kernel 2.6.25-2-686 allowed me to see ~2GB RAM.
Also, there is a noticeable difference in performance with some programs, such as flight gear.
Yeah, I used synaptic to read the description of the different kernels available.
The desc riptions tipped me off as to what to use.

But now we know, and that's half the battle.
So, if any of you come across a problem like this, think about what kernel type to use.
