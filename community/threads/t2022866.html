I don't think putting the router in the attic will prevent wardriving - the extra few metres won't affect the reception the wardriver gets.

WPA security will be a better security measure I think.

A dynamic IP isn't a problem if you want to host a website. Use a DNS service like DynDNS which includes a little program which calls out to update your IP. I have a dynamic IP and I still host a website fine using DynDNS.

Oh, and the word you are looking for is static. Few domestic ISPs allow you to have a static IP. A dynamic IP is where it changes which can be a pain in the ass if you don't use a dynamic DNS service. Having a static IP is easier - I think you've got the terms mixed up!

I think it's WEP that can be cracked that quickly, but I may be mistaken.

Every network device made will have a (generally unchangeable unless you're crafty) MAC address assigned to it. This is of course unique. A pretty good security method is to set the MAC address allow list on the router to only allow the computers' MACs in your network to connect. If someone tries to connect who has a MAC which is not on the list, it won't work.

However, MAC addresses can be spoofed so it's not a 100% safe method, but I'd say the combination of MAC blocking and a good key should stop most wardrivers.

With certain Linksys routers which ran a mutilated version of Linux, you could flash the firmware to run something of your choice. I don't know about Netgear's routers though. It might have a handy DNS client for DynDNS built in though - my BT router/modem does.

There's not many really amazing things you can change. Just read the manual and poke around when you get it.

Individual firewall/antivirus software for your computer is kind of redundant when you have a router (no incoming connections unless explicitly told otherwise) and you are fairly competent at avoiding noob activities (e.g. downloading random executables and running them on full admin privileges).

Quote:
where would be the best place to put the router+modem?(i have basement, 1st floor, attic) I was thinking of putting it somewhere in the back of the house, in the attic, so people don't wardrive...
Put it on the floor it will be most used on. I've found that routers penetrate quite well through a couple of walls perhaps, but not really through the actual floor. Too much metal/wood in the way. Get the router high up as well, and keep it well ventilated if it doesn't have a fan.

Risk of wardriving shouldn't really be part of the equation. You can make sure of that by securing it.

Quote:
is there any way of making your IP, not static. but the other way... where it stays the same. dynamic is the term? without paying verison, because i think website hosting from your computer should be free!
With IP addresses, static means constantly the same and dynamic means changing on every re-connect your router makes. Most (if not all) ISPs hand out dynamic addresses because of IP address shortage with IPv4, but services like DynDNS can keep track of your ever-changing IP address and make it accessible through a constant domain name -- if you wanted to host something from your machine that is.

DynDNS is free when you use their basic service with one of their subdomains.

As for the security of the router,
  • Enable WPA encryption and specify a long alphanumeric string as the passphrase.

  • Note down the SSID, then turn off SSID broadcasting. This effectively makes the network invisible to everyone except those that specifically know its name.

  • Turn off remote access to the router's web interface, if that's possible.

  • You may want to turn on MAC filtering. This requires you to perform the tedious task of entering in the MAC codes of all the trusted computers, but afterwards it means nobody can connect to the network unless their machine is on the list of trusted MACs. This adds even more security -- they're not going to brute-force a 48 bit MAC code over the network, and if they physically came into your house to find your MAC, well they could just hook up directly into an ethernet port anyway.
