Re: Java chatroom (not web based!)
What I would do is write two programs. One to act as the central server and one to distribute to your users that acts as the client.

The client simply connects to the server and sends it the typed messages. The server is constantly listening for the clients sending messages and when it receives one it adds it to a buffer. The clients request this buffer every 2 seconds and display it on their screen.
