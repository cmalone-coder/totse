Re: Best OS for file servers
Fedora 8 will most certainly do the job as a file server, as the majority of distributions.
GNU/Linux is not the same as Windows there is no server/desktop/whatever version of a distro (except a few exceptions).
If you want to play with different distros, you might want to use a different partition than / to store files, create a different partition for /home and don't format it when installing.
How to do this will be in the distribution documentation.
It's not distro specific, but different ditros might use different tools for partitioning.

To use X11 application you need to configure X11 Forwarding. Here is an article i found doing a quick google search:
http://preview.tinyurl.com/659kr3

I do not know if putty supports it, but cygwin with x installed does.
You still have to type the commands though.
There are alternative to ssh, such as vnc, but i still haven't given it a try.

The FreeBSD honeymoon begins only after reading the whole documentation and using it for a couple of weeks.
If free time is a limited resource don't bother learning FreeBSD for a simple home filesever. Unless you already know what your doing, of course.

Re: Best OS for file servers
BSD is great, but it only gets noticeably better than Gnu or Linux options when you have a _lot_ of really heavy iron. If you just want to have a samba share, go with something like Gentoo or even Ubuntu Server if you aren't too serious. If you have enough drives for a zfs pool and you have some gigabit NIC's, FreeBSD is 100% the way to go. OpenBSD is a good option too especially if it's net-facing.

Re: Best OS for file servers
The X server is a server that provides windowing and a GUI to a UNIX (or other implementing) system. In UNIX tradition, it's done on TCP/IP, so you can run X applications remotely over an SSH tunnel.

You really shouldn't have an X server on a server. It's just a security risk. This means no VNC either. Just use ssh.
