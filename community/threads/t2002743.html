How to really change you're ip address
Note: this may not work with all modems

First you need you're modem private's ip address.
Go into you're modem's configuration.
(Typing modem's address into you're browser)
Get you're modem default user and password.
If you can't find the manual, just google the name of you're modem+default login.
Now it's time to find the connection wizard.
Usually it's a PPPoE connection.
Diconnect it, then reconnect it.
Now you have a brand new ip!
