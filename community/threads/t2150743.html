I use netbeans for java.
For shell scripts and C++, jedit with a similar-to emacs macros.
Any emacs clone that is not emacs if Xorg is not installed.

Stay away from IDEs and utilities like cmake until you are done learning C/C++, they can get very very addicting, particularly when learning a new language.
They also dumb some the things which you should learn, such as Makefiles.
Use a plain text editor and gmake.
