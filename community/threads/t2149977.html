Ignorance is the only universal human default.

It means that if you generated say a PGP key, if they could find out what seeded the random number generator, they could find out what your private key was (if they've cracked yarrow, I don't really know that much about encryption). That's for OS X. On vista, the PRNG is backdoored and it's possible that the NSA knows every bit coming out of it.

Typically, on UNIX-based systems, the RNG is at /dev/random, which harvests REAL entropy from hardware events. Hardware is physical and decays, so things like keyboard interrupts and disk reads happen with an element of "randomness". You can also harvest entropy from your speaker static, surrounding sound, or webcam reads, if you install other programs and have the right hardware. What Apple did was they removed this RNG and replaced it with another copy of /dev/urandom, which is a cryptographically secure psuedo-RNG. On Gnu/Linux, /dev/urandom is just a never-ending source of randomness, because it takes /dev/random as a "seed" and then uses a cryptographically strong algorithm to produce more "random" bytes.

The best thing to do is to buy or build a real hardware RNG. This is what I've decided on.

Also, you should only install FreeBSD if you're willing to learn a lot very fast. FreeBSD is a great OS made by great people, but it isn't for newbies. The reason I said "just install FreeBSD" is because in true Apple tradition, OS X is a ripoff of FreeBSD.
