I noticed that there is already one here on Totse about American Express account numbers, but it is a little inaccurate. For example - the author tells that in a lot of situations if you have an account # with the last 5 digits XX005, then a lot of times they will issue an account that has the exact same number except the last 5 will be XX017...this isn't a different account like the author believes it is just an additional cardholder on the account, so if I got an AMEX card and wanted my girl as an additional cardholder that is how the numbers would appear. Other then a few things like that the file is pretty accurate. I'll read over it again and if I found more things in there that need to be corrected then I will type up my own file.

About the number to call to check credit limit and the balance and shit like that - if you are in the U.S. you can call the toll-free directory at 1-800-555-1212 and get a number for the issuer of the card. Most of the time the number given will be customer service, but if it's not then the representative will transfer to customer service so that you can find out the limit and shit. The problem with this is that you have to pass an ID policy before any account information can be released to you - it's federal law. Most of the time this ID consists of name, date of birth, and the last 4 digits of the social security number, so this could make it a little difficult to check that shit. If you call the issuer and you get an automated system that lets you check the balance and limit then most of the time all you need is the last 4 of the social security number, so that makes it a little easier.
