Network (in)Security Interesting hacks and cracks. Info on firewalls, TCP/IP, encryption, networks, and security. The ins and outs of the phone system, caller services, how things work, what's illegal and what's not, cellular phones, beepers, telephony legislation, the PUC, ISDN, taps, who's listening, and switches. Talking about phones, hacking systems, technical advice, and such is completely LEGAL in the United States -- it's covered by the First Amendment. What's illegal is conspiracy to commit a crime. So if you say something like "Meet me at 2am so we can crack a can" or "I changed my cell phone's number myself" you are criminally liable. Stating "You can crack a can by doing thus-and-so" or "If you wanted to change a cell phone's number, you could do it like so" is perfectly OK. Posting passwords, calling card numbers, or credit card numbers is forbidden on this network. Posting such info will get you booted off the net.

Yes, I think I can help you out. Keep in mind that I read every topic in this forum, and it's probably better to use a more descriptive subject line. If you have a question that I can answer / feel like answering, I'll do so as soon as I see it.

I assume you are running Windows XP? This is a result of a misconfigured security policy. It's meant for use in corporate computing environments to prevent users from screwing up their systems, but under certain circumstances a virus (I believe the Torvel (http://securityresponse.symantec.com/avcenter/venc/data/w32.hllw.torvel@mm.html) worm is one of them) or certain pieces of spyware may enable this feature without your intervention. Scan for viruses and spyware first using your preferred programs.

If that doesn't do it, this is how you disable the policy:

<UL TYPE=SQUARE><LI>Go to the "Run" prompt.

<LI>Execute "gpedit.msc".

<LI>There is a threaded view on the left side of the window.

<LI>Go to User Configuration, Administrative Templates, System.

<LI>Disable "Prevent access to registry editing tools".

<LI>If that doesn't work, there may be a function to do so under "secpol.msc". Check under Local Policies, Security Options.</UL>If you have trouble with that, save the following as a ".reg" file (e.g., "restore.reg"), and execute it:

code:<pre>Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Microsoft\Windows\Curre ntVersion\Policies\System]

"DisableRegistryTools"=dword:00000000</pre>

If that doesn't work, I'll have to write a program to do it, but hopefully one of the methods I outlined above will.

Oh, and for future reference, this type of question belongs in T&T, but I'll keep it here for now.

Ok, I just finished writing a program for you that will do the same thing as mentioned above. "EnableRegistryTools.cs", written in C# (yeah, C-Sharp; shutup):

code:<pre>using System;

using Microsoft.Win32;

class EnableRegistryTools

{

public static void Main(string [] Args)

{

RegistryKey key = Registry.CurrentUser.OpenSubKey("Software\\Microsoft\\Windows\\CurrentVersion\\Poli cies\\System");



if (key == null)

{

key = Registry.CurrentUser.CreateSubKey("Software\\Microsoft\\Windows\\CurrentVersion\\Poli cies\\System");

Console.WriteLine("Key Created...\n");

}



if (key.GetValue("DisableRegistryTools") != null)

{

key.SetValue ("DisableRegistryTools", 0);

key.Flush();

Console.WriteLine("Key Modified...\n");

}



Console.WriteLine("\nDone.");

return;

}



}</pre>
