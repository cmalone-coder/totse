Re: New to all of this... looking for help
"1. is there a program i can download to access a person's ip adress."

Clarify what you mean by accessing an IP address.

"2. if i can get directly connected to a person, lets say on AIM or ICQ, how would i get their ip?"

In a DOS (disk operating system) shell type: netstat -a. This will show all connections made to your computer along with information like the IP address and the port number of the connection. If you type this command before you go and connect to say an aim server look at the listing and then connect to the aim server you will see a new connection and that is the aim server. You use this connection when doing things on AIM. But when you make a direct connection you make a connection with the other persons computer. When talking/sending data to this person you use this connection instead of sending to the server. Now if you netstat when a direct connection is made you can see the new connection and see it is the person you connected to.

"3. once i have the ip, is there another program i need to have, or change my settings, so i could type in their ip and have access to their C drive?"

Its not that easy, im sure there are programs that you can do this with but i don't know of any. Im not even sure if they work anymore, or you need some sort of setup. Most things involve that you get the victim to run the software on their machine. Which could be easy or quite difficult depending on the victim.

"4. Im on a cable connection, if the person's computer i hacked into figured out my ip, which is always the same, should I change my IP?"

Typically cable modems have static IPs, which means they are always the same. If you change your IP it could conflict within the network (the cable modem loop).

When you connect into someones computer by the same token you can find their IP they can find your IP.

There isnt a scroll command, the buffer is only as big as the screen. Im sure you could change this, but its easyer just to run each command in a different window.

Also if you type 'netstat -n > foo.txt' the output of the netstat command will be routed to the file foo.txt (it will replace a foo.txt if it already exists).

quote:
Are there any other useful DOS commands i should know before i go trying to hack into this person's computer?


You will need to know more than just thier IP to gain access to thier computer, look up some windows exploits.

As for the output of the netstat commnad...

1.Proto - The Protocal used
2.local adress - The origin of the connection (Your IP)
3.foreign adress - The destination (Thier IP)
4.state - What its currently doing
