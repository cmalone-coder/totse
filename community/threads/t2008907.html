Re: 2nd partition not mounting. help :(
Example:

/dev/xxxx /mnt/xxxx auto user,async,auto,rw,dev,exec,suid 0 0

Replace the xxxx by the name of the device.
You will be able to use it as a regular user (not root), if you don't want it to be accessible by regular users, use nouser instead of user.
For a better understanding of /etc/fstab see:
http://tinyurl.com/fzhoj
I recommend you learn more about /etc/fstab.

Note: Don't forget to create the /mnt/xxxx directory, if not already present. You can use another path than /mnt/xxxx though. I use /home/user/myfiles for /dev/hda2.
