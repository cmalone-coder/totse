Re: Telnet commands
I think its a miss directed question.

As everyone has been saying telnet is a protocal a means of doing something. In this case opening up a shell on a forgein host. Depending on the host will be a seperate set of commands. Most likely you will be connecting to some kind of *nix system. The typical command paths are: /bin/ and /usr/bin/. Using the list command (ls) on these directories will yeild you the commands. For most commands a manual should exist for them just type:

man command_name_goes_here

to pull up the manual. Also you can try

command --help

And last but not least you could always web search.
