Re: I am an idiot and forgot my password for xp sp2.
One thing about those programs that let you change the password:

If you use EFS (Encrypting File System, most visible as the "Make this folder private" option in Windows Explorer), then the encryption key is generated from the password. That means that changing that password without using Windows' built-in utilities (and knowing the old password!) will make those files unreadable, permanently, unless you remember the password later and change the password in the SAM back.

Just something to think about.
