FrontPage

If you are a noob to HTML, use Frontpage. It is easy to use, and works like Word except that it does web pages.

I use it because coding in Notepad takes too much time.

You have to look up any things that you don't know, and if a tag only has a beginning tag ( <html> )and no end tag ( </html> ), you fuck up the whole thing.

So I use FrontPage, mainly for my eBay auctions, because it looks pretty fucking proffesional.

If i have any problems with it, I go into the code.

Frontpage has 4 modes (Code, Design, Code & Design, and Preview)

And you can make burned copies of it that actually work.

I fully agree. HTML is so easy that you don't need to spend more than an hour looking over how to use it. If you get stuck on something with HTML, use another website as an example - they're made of it.

When I first started making websites I used dreamweaver (especially for forms and tables). Unfortunately, dreamweaver makes a lot of mistakes and assumptions. So I started picking apart the code that dreamweaver made for me.

So if you do use dreamweaver, just promise me that you'll learn what it is doing and why it's doing that. Read the code that it produces and try to understand it (it's not that hard at all). It will help you in the long run, trust me.
