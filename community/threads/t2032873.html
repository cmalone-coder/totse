If you are a noob to HTML, use Frontpage. It is easy to use, and works like Word except that it does web pages.

When I first started making websites I used dreamweaver (especially for forms and tables). Unfortunately, dreamweaver makes a lot of mistakes and assumptions. So I started picking apart the code that dreamweaver made for me.
