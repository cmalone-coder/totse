Feature List - As of 16th July, 2002
- Added support for mods. Now works with all mods.
- Main menu totally re-worked. Now has a mouse driven UI similar to Quake III Arena's, with complete menu art overhaul.
- New Shader system that works on 2D, 3D and model surfaces.
- New Console.
- New Smooth font.
- Added shadows to fonts.
- Added various commands to give better control over Quake 2.
- Added Quake III Arena style console typing, allowing the type of functionality of the Quake III Arena Console.
- Added 3 levels of fogs to maps by using the command r_fog 0-3.
- Added the possibility of having large textures ( 4096x4096)
- Added 32bit Targa image support for use on textures, skins and images.
- Added Jpeg support for use on textures, skins and images.
- Added new file system called *.pk2. This system is a zip format like that of Quake III Arena allowing zip files to be used instead of *.pak files.
- Changed loading order of pak/pk2 files. Now: pk2>pak>Folder.
- Changed drawing order of textures. Now .tga>.jpg>.wal.
- Changed drawing order of skins. Now .tga>.jpg>.pcx.
- Changed drawing order of 2D art. Now .tga>.jpg>.pcx.
- Changed various in-game object models/skins. For example, the Strogg banner.
- Added Quake III Arena style lagometer.
- Added new shadows. Now theres none, oval, solid, and transparent.
- Added 32bit Targe crosshairs to replace older ones. All have Alpha Channel support.
- Completely re-worked the HUD system. You now have a static sized HUD, complete with new icon/number set.
- Added a Quake III Arena style weapon selection bar that pops up when you switch weapons.
- Added a Frames Per Second counter in the top right corner.
- Resized all default id skins for models to numbers that are diversable by 2.
- Slightly re-worked the particle system so that each particle is loaded from an image file.
- Texture/shader set 1/4 complete. There's roughly a 1/4 of id's textures that now use shader effects.
- Water warping.
- International keyboard support.
- Add muzzle flashes to all weapons and to the monsters fire.
- Re-do particle system.
- Complete work on shader system.
- Re-Making the skins.
- Re-Making the models.
- Complete work on Extreme mode for Single Player.
- Add chat bubbles over player's head when talking.
- Re-define Quake II Multiplayer and make it more natural. i.e. proper Team Play, and our own VCTF.
- Re-make menus for Mission Pack "Ground Zero" and "The Reckoning".
- Add .avi playback.
- Add more on-screen effects, such as blood dripping on the screen when you gib an enemy to close, a steamed up screen when getting out of water, cracked screen when killed etc.
- Add Loading screen.
- Add real weapon decals. No silly light hacks thanks.
- Add real blood. See above
- Lens Flares.
- Light halos.
- Possible weather effects in certain maps.
- New Multiplayer game modes.
- Re-working the Single Player A.I.
- Re-making the textures.
With more on the way, the basic idea is that they are trying to bring people back to the good old quake 2 days by improving the experience and giving the engine away for free.
