I'm currently trying to find a decent *nix for what I need. I might have to switch to windows on my main box as Linux is too time consuming.
I know how to use a command line, but don't want to. Also modern linux cli is so different to what I started on (BSD servers and the like).

Anyway here's a list of problems so far. I know I suck for not being able to hax all these problems, but as a lazy son of a bitch in two-thousand and fucking eight I expect my OS to be well written and work without constant nurturing.

1. Firefox crashes when on youtube. A lot of people have this problem, so it's not just my crappy computer.

2. Sound output won't work in a lot of applications. Would you like to use ALSA, OSS or that new sound system thing today? WTF? Get your shit sorted linux, pick a standard and stick with it.

3. Experimental/incomplete programs in package list. Some of these like gnash flash player, require enormous computing power from a processor. Others, like Miro, are easily broken by packages and configs or something. Miro on My machine won't run today, but ran fine yesterday. WTF?

3b. Yum and pirut are slow as a mother-pig in reverse.

3c. Packages advertised as wonderful and complete when they suck.

4. No MP3 support out of the box. WTF? Licensing? Free software? Call me ignorant, but I'd prefer if my OS supports more than OGG Vorbis sounds.

5. No Video player. - That's right, no video player. mplayer has sound problems and looks like crap, videolan is buggy, has sound problems and looks like crap, and the others like Kaffeine have no support for anything. I'd just like one that works, and doesn't crash constantly, flicker, have sound outages, etc. VLC on windows and Mac is indespensible, on linux it sucks.

6. No installers. The only installation program I have seen done even remotely right on linux is the OpenOffice.org installation. Even that is Java, and requires a user to log on as root to install. If you aren't root, it gives you some stupid unhelpful error.

7. Everything requires you to be root. If you aren't root you can't even move a file from /home/user to /home . Mac OSX finder and programs will display an authentication box to enable people to do root actions. Linux just says ERROR, maybe if you're very lucky you get a "Permission Denied"
