I'd say your host provider is running a magic_quotes directive:

Quote:
When on, all ' (single-quote), " (double quote), \ (backslash) and NULL characters are escaped with a backslash automatically. This is identical to what addslashes() does.

http://www.php.net/magic_quotes

Quote:
Originally Posted by Aragami
stripslashes() on the output?

Or turn off magic_quotes.
This. Preferably, turning off magic_quotes

Also:

Code:
include ("page");
If you're purely passing a variable there's no need to quote it.

Code:
$page = $_GET['page'];
You should be checking that the GET param 'page' is set first, using isset ().

Code:
$FILE = fopen("$page", "rt");
      while (!feof($FILE)) {
    $text .= fgets($FILE);
You can simplify this to:
Code:
$text = file_get_contents ($file);
Also, you should be checking that $file doesn't start with '/' or contain '~' and '..' to prevent path injection.

Not having a dig at you, though.
