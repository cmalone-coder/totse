Re: new partition for umbuntu
You have to make the partition with the Ubuntu CD because Windows won't format the partitions with a linux compatible file system like Ext3.

When your installing Ubuntu don't click Guided partition click the Manual Partitioning option and do it manually. I'm assuming your going to wipe out any partitions that are already on your comp and start from scratch so just delete all the partitions until all thats left is Free Space then click Create New Partition and make it whatever size you want.

If your doing a dual boot I recommend making 2 Ext3 partitions and install Ubuntu on 1 of them and you can reformat the other one later. Remember to make a SWAP partition of about 2-4GB.

Re: new partition for umbuntu
Stop acting like an idiot and give more detail.

If someone said there was an 8 megabyte partition to me, I would serious question what block device he or she is looking at. HDDs haven't been incredibly low like that for decades.

If you're resizing the NTFS partition, I suggest you don't make it any less than 25 GB. If you are able to resize it and it corrupts at 25 GB or lower, then you need to change how much you are resizing it. I then suggest you reformat with Windows and try to resize to 40 GB. You only need about 5 GB to play with a GNU/Linux distro.

If you keep acting like a twit and posting shit in terms of thx and l8r, I'm not going to respond. You didn't even follow the most essential rule that even Windows experts know: Give the specs.

Incase you didn't notice, yeah the programs would look identical. Because both of them are GParted. One is simply a live-cd (GParted Live-CD, I presume?) with the program inside of an X-server. The other is a GNU/Linux distro with the program and an X-server. Some versions of GParted are bad, because they don't undo things. For example, versions of GParted have a habit of doing steps you later decided not to have occur. If doing something and deciding against it, restart the programs. You'll save time that way.

Alright, my intuition says if you say an 8MB partition, you might have been looking at the cd-rom drive or some other block device. If you're using gparted, familiarize yourself with the drop-down menus and such. If you can't see your drive listed anywhere, try messing with the bios. if you need to reset the bios, just make it go back to its defaults.

besides that, if you can't see your device through gparted, I'm going to assume the linux kernel and the modules don't work with your HDD. That seems like an odd thing to say, but it's possible. Otherwise, try a more recent version of gparted live-cd. Maybe try an ubuntu live-cd.

If you want to back up your windows xp partition, take a look at something called "clonezilla." it's an awesome thing to prevent you ever losing you windows xp system. You might want to remove programs and downsize everything (remove movies, games, mp3s, java, etc..) in the Windows partition if it's above something like 15GB.
