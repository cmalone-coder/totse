dur, i broked my ALSA!
so i'm running Fedora Core 6-x86_64 at home on my desktop, which has several sound cards installed on it (an integrated, a 4 channel Sound Blaster, and a Sound Blaster Live! 5.1).

my main sound card is the Sound Blaster Live! 5.1, which Fedora Core didn't have any problem initially detecting and defaulting to.

the problem came when i was messing around with the config files, trying to modify the way surround sound worked (so that the rear speakers would play, even with audio sources with less than 6 channels).

so somewhere in that process, i borked my ALSA installation. i really don't know how either... i had to manually create a .asoundrc file in my home directory, played with a bit, and when it wasn't working the way i wanted, deleted it. unfortunately after that my sound card stopped working entirely, even though ALSA is supposed to operate fine w/o a .asoundrc file.

now when i go into the sound config GUI's that came w/ FC6, it still detects my card, but there are no selectable PCM devices on that card, when there used to be about 4 different ones.

the best thing i could probably do would be to completely reset or reinstall alsa, however fedora core does not make this easy, as its completely integrated and is not recognized as an independent package. does anyone know how to do this, or possibly how to repair my ALSA configuration?

Re: dur, i broked my ALSA!
Add this above the install and remove lines in the /etc/modprobe.conf file:
Code:
alias snd-card-0 snd-emu10k1

options snd-card-0 index=0

options snd-emu10k1 index=0
This will require you to actually reboot the computer, so that all the module bindings are correct. If you have multiple sound cards, remove them or if they are onboard, disable them in the BIOS, and try the above suggestion. If it works, there is obviously a problem with the driver binding another device first, or some other error with ALSA choosing a different card as card0, the default mixer device.

Let me know the results so we can determine the exact problem.
