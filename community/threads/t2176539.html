Most people like a torrent client that's a bit more sophisticated than the regular Bit Torrent client. The two biggest choices out there are Azureus and uTorrent. Azureus is written in Java so it runs on any platform - downside is that it uses pretty much all of your ram, lol. uTorrent is brilliant in terms of ram/cpu consumption but until now it's only been available for windows.

In fact, when I was running utorrent on linux under wine, it STILL used less cpu/ram than Azureus.
