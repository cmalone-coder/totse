So I tried debian for the first time

Community > Technology > Everything *NIX

#1
2008-03-19, 23:59
Zok
Forum Administrator

Amazing!

First let me say that I've always been a huge slackware fan. I enjoy configuring everything by hand and fucking with dependencies. I use fedora on my server and I can't tell you how fed up with yum I am. If it's not yum that's broken, it's rpm, or it's SELinux. Fedora is really nice and pretty easy to use, but it's given me a lot of trouble. So anyway...

I downloaded the net install iso, burned it out to a disk, and went through the install. The install didn't take long at all, the computer booted up with no trouble, and I was brought into Metacity. I ran the updates manager, it downloaded and installed all the updates I needed. Then I added 'sid' to my synaptic host list (which caused a bit of trouble - I had to do a bit of research/fiddling in order to get it to work properly). I installed updates from sid and then proceeded to add the software of my choice. It was little trouble to install my drivers for my graphics card, sound card, and the like.

I was quite surprised with how easy it was to install new software and how well the package managers worked - no more dependency problems. I can't say I'm all that thrilled about everything being automated or run through a GUI (I know all the same command line tools exist - I just feel like it's being dumbed down for me).

All in all, I say give debian a try. It's VERY easy to use and get running the way you want. It's not too dumbed down, but it's not a do-it-your-fucking-self distro. A very good beginning point.
