The LiveCD won't be an accurate performance indicator, as it'll be slow going through RAM.

Gentoo typically is able to run pretty light, but installing applications will take a while. I'd recommend using Gentoo if you know exactly everything you want to do on the box. Install what you need in the first week, emerge --sync && emerge -auDN world every other week (late late at night in a cron job; that will not let you use the machine).

I've heard good things about Arch, but really any distro will be fine as long as it has a modern kernel and a good package manager. Don't use anything like Puppy Gnu/Linux, DSGL, or anything like that. Those are optimized for size, not actual 'lightness'.

The real bottleneck will probably be at the video layer and in expensive high-level language runtimes like Java or Ruby. Stay away from those two, use a good video card (it doesn't need 3d anything, it just needs to be a driver that will push work to the card instead of the CPU, nv will work, as will any other driver, just don't use vesa), and use a lightweight desktop environment. OpenBox, FluxBox, XFCE, and E17 are good (fuck e16, e17 is amazing), avoid GNOME and KDE like the god-dammed plague. If you're using Gentoo, you can put "-gnome -kde -glib -qt" in your USE flags to stay away from needing that stuff and to make emerging apps faster.

To sum up, use Gentoo, check out the Gentoo wiki for tips on how to keep your system nice and optimized, master the art of USE flags.
