Re: Is there a way to make a network invisible?
Completely invisible, i don't think so.
To 99% of people, yes, turn off essid broadcasting in the router web configuration interface.
If the wireless is already configured, the wireless network will still be visible on your laptop and whoever *saw* the wireless connection.

1. Turn off essid broadcasting
2. Change essid
3. Use the configuration wizard to configure the connection manually.
