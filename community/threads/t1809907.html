There is something more, you are that something more. The concepts of freel will and the like can be confusing because....well because we only have language to describe our thoughts and this weakens them greatly. Language is a simple structure, a set of rules. So if you can only use language to think, you can only think using that said set of rules. If you're a thinker, and chances are if you're here you're a thinker, then after so long the structure of language has run every possible course and it begins to feel as if you just go through the motions. It feels like it's all been said before, and interest in conversation begins to lack as you notice the things you say and the things other say popping up so frequently to the point of annoyance.

You can't really change "free will" like flipping on a light switch, but you can kind of use it, coax it along a path you feel like doing. It doesn't look like free will experiencing it, but throughout the big picture you can see fluxuation, breaths of fresh air, and creativity. You can use the repetitious set of rules to be anybody...this time around. You could be Einstien this time around, you could be Krishna this time around, or you can let it all get to you and be that guy joe who works down the street that gets drunk and watches the game on weekends.

That something more is merely clouded by perception.
