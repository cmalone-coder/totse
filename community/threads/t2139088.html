Looking back, I would recommend OpenBSD. Installing OpenBSD will give you a better idea of how nix operating systems are different than windows. Ubuntu in many ways tries to emulate Windows to make it easier to use, but when Windows users find things that worked a certain way in windows don't work the same in Linux they get frustrated. Thats why learning Linux is difficult at first. Windows users have a hard time learning about user groups, partitioning, file permission, and using a command line. I would try OpenBSD for a few days then wipe the drive for an Ubuntu install. Search Youtube for a video on how to install OpenBSD. Partitioning the drive is difficult if you dont know what youre doing.

Originally Posted by rabbitweed

Quoted for fucking truth.

I learned off of slackware (7.4) when I was in highschool - no linux experience whatsoever. It's notorious for being one of the "trickier" distros for beginners but it's also been named one of the most "linuxy linuxes there is".

To be entirely honest, it took me several weeks before I got all of my drivers and devices working - hell, it took me several days just to install it and get a working desktop env. But it was the best learning experience ever. If you're serious about learning linux and don't mind reading manual pages and googling things, go slackware. You can't expect to learn anything about linux if you hide linux behind fancy GUI's and installation wizards... Learn how to use the command line. Learn to install things from source. Learn how to use vi.
