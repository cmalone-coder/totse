I am fairly new to shell scripts, but I was wondering if it would be easy to write a bash script that would login to hotmail, open new messages, then write the email to a file or just print it on the terminal? This could probably be included in a simple POP or IMAP server. I'm thinking the script would consist of:

1 logging in
2 download inbox page
3 parse inbox page to get urls to unread messages
4 download the newest unread message
5 parse out the subject, sender, body, etc
6 print subject etc to file
7 repeat 4-6 for other unread messages

I'm not sure how POP and IMAP servers work, but I don't think it would be too difficult to adapt it. This is probably all theoretical, I doubt I will actually go through with this, but sometimes it's fun to think about stuff like this.
