Using DSL will force you to learn the linux filesystem and understand some NIX internals. Other than that, DSL is not the best start for a beginner.

If you want answers, then SEARCH around the DSL forum. The answers are there. There is also a wiki devoted to DSL. I've tackled each one of the situations you are going through. I don't feel like giving answers to them, though. If you want wireless info, then I might help.

blah
http://www.linuxquestions.org/questi...e-help-431472/

When I came back into Linux, I started with DSL. That was a half-assed experience that got annoying very quickly. DSL isn't finely tuned enough, and I would suggest it for the novice/intermediate user that needs a small distro with some abilities. It's good for systems that want a live-ram setup and quick loading times.

DSL isn't really for the complete noob. It can be, but it doesn't give the feel of a serious Linux OS. It's a waste of time if you're a noob. You might as well install redhat and read through a redhat book.

Feather Linux is a good alternative if you are low on RAM.
I would more likely suggest Puppy Linux. Puppy can be booted from a USB, too.

Both of those OSs can work in live. Puppy Linux is much better if you want to learn Linux. It can also force you to learn a couple Linux programming languages if you want more control. The forum userbase is still constant, and there are many programs that have been built for it.
