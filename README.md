# totse.com Archive

A rebuild of totse.com (1997–2009) from an offline backup, restored through the site's real original template — actual chrome, fonts, and layout pulled from the archived pages themselves, not a reinterpretation.

This is a work in progress. Known gaps:
- Internal links between rebuilt pages still point at the original archive's relative paths, not this site's structure — cross-link remapping hasn't been done yet.
- Long BBS threads that originally spanned multiple pages are merged into one combined page rather than paginated.
- No content review pass has been done yet — this is a straight, unfiltered restoration of the original site's text-file library and forum archive.

## What's here

- `en/` — the text-file library (drugs, technology, religion, fiction, and more), one folder per original category.
- `community/threads/` — rebuilt BBS threads from the forum archive.
- `styles/`, `images/`, `assets/` — shared site chrome, recovered original ad images, and supporting scripts.
