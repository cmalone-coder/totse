T1 Signaling

type t1.hlp

OSA : Outbound Signaling bit A (to network from VRU)
OSB : Outbound Signaling bit B
ISA : Inbound Signaling bit A (from network to VRU)
ISB : Inbound Signaling bit B

Implementation notes:

For all E&M and Ground Start protocals, if the VRU goes from off-hook
to on-hook before the CO, the VRU will wait for the CO to go on-hook
before declaring 'Hangup Complete'.

Loop Start emulation does not provide a disconnect signal so the VRU
will declare 'Hangup Complete' imediately.

Rockwell D2 and D3 protocals may provide a disconnect response to the
VRU if the VRU hangs up first but this is not guaranteed. Therefore
the VRU will not wait for the release from the switch before declaring
'Hangup Complete'.
