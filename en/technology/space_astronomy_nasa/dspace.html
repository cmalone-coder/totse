Common Names of Deep Sky Objects

Below is a list of objects that have a common name associated with
them, for one reason or another. These names are a general description of
what the object looks like (this is subjective, with respect to the viewer
of the object), the name of the discoverer of an unusual object, or the most
prevalent object of a constellation. The list below has been compiled from
names found in NGC 2000.0, Burnham's Celestial Handbook, Sky Atlas 2000.0,
Observer's Handbook 1990, Uranometria 2000.0, and names I have heard objects
called at star parties. Not all objects are visible in amateur's telescopes.

I have tried to verify the objects and their names; for reference I
have used Uranometria 2000.0. I have given the chart number, associated
with the coordinates, and placed an "*" after the chart number if the object
is listed but found no name, and an "!" after the chart number if the object
was not found.
----Alan Sifford----
