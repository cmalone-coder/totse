The Automated Nuclear, Biological and Chemical Information System

BOS: MOBILITY/COUNTERMOBILITY/SURVIVABILITY

IPT: CHEMICAL 
------------------------------------------------------------------------

INITIATIVE: ANBACIS - Automated Nuclear, Biological and 
Chemical Information System

INITIATIVE REFERENCE NUMBER: 

CATEGORY: PROTOTYPE

MATERIEL DEVELOPER: PM OPTADS 

------------------------------------------------------------------------



INITIATIVE DESCRIPTION

The Automated Nuclear, Biological and Chemical Information 
System (ANBACIS) is a separate software program that resides on 
the same Common Hardware System (CHS II) platform that 
contains the MCS/P Baseline software. ANBACIS will not be 
FULLY integrated into the MCS/P software. Instead, the MCS/P 
Baseline will invoke the ANBACIS program via its Executive. The 
probability that ANBACIS will degrade the MCS/P Baseline 
program is minimal. ANBACIS is not a stand alone system and 
should not be considered as one. ANBACIS is invoked by NBC 
personnel in order to input various NBC reports into the database 
for processing; or to conduct risk analysis and vulnerability 
assessments. The MCS/P baseline will alert the ANBACIS 
operator when an NBC message is received. The operator must then 
start the ANBACIS program in order to process the NBC report. 
The MCS/P Baseline software will not automatically start the 
ANBACIS program.

Hardware maintenance is the responsibility of PM OPTADS. The 
ANBACIS program will be directly loaded onto the CHS 11 hard 
disk drive, along with the MCS/P baseline program. In the event of 
program failure or difficulties the operator should contact the Help 
Desk, who will contact the contract repair personnel. PM OPTADS 
will coordinate with the US Army Chemical School and its 
contractor SAIC for repairs and fixes to the resident ANBACIS 
program. The USACMLS will not have a permanent on-site repair 
team.

SPARE CONCEPT

None is. required for ANBACIS. All hardware is owned by PM 
OPTADS, and as such is their responsibility. The ANBACIS 
program will not use ANY hardware separate from the CHS II 
platform supplied by PM OPTADS.
