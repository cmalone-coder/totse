List of UK NDCs (NDC = National Destination Code; which CCITT say we should
be using now, to "harmonise" terms like NPA codes, NACs, and NNG codes).

There have been quite a few changes in the UK recently ..... this list is as
accurate as is humanly possible to be, up to 1/8/92. In most cases the code
identifies one area (or "charge group" ie group of exchanges which have the
same tariffs - broadly equivalent of the US "LATA", but NOT quite the same).
In some cases there are several charge groups covered by one code, while in
other cases one charge group is covered by more than one code.

To keep this list simple, it includes the code and the main town (in the
principal charge group, where there is more than one charge group on the
code). In most cases where more than one charge group is covered by one
code, all the subsidiary charge groups are contiguous with the principal
charge group: but beware - there are a small number of exceptions.

For non-UK readers of this list, it may be helpful to remember that over here
cellular and (most) paging companies have numbers on their own "branded" NDCs
because calls to cellular numbers are sent fully paid - there is no charge to
the recipient for the airtime. This makes for very high call charges, and is
why they have separate codes, rather than being fitted into the geographical
(NPA) number structure as in World Zone 1. Don't ask me WHY this is so !

Also, there are separate NDCs for our equivalent of 800 and 900 numbers; the
latter having separate codes for both each vendor, and each tariff. We have
3 tariffs for these services, currently approx 0.38, 0.48 and 0.75 UK pounds
per minute in peak time for callers using BT as their LD carrier. The other
LD carrier (Mercury) offers slightly lower charges.

All codes are shown in their international form - the prefix "0" is required
for all calls to numbers using these codes, if calling from within the UK.

Please note the numbers opposite each code are the quantities of numbers in
use under that code, as calculated by a computer prediction formula. Where
we have had access to the official data, the figures were found to be very
close indeed, apart from a slight north/south variation across the country.

The code 91 is a special case where three charge groups were merged onto a
new NDC with full (7-digit) local dialling between them. The first digit
of the 7 digit number indicates which charge group the called number is in.
