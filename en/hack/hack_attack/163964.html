About network shares:

Most security failures are caused by unprotected network shares on Microsoft windows 9X/ME and NT machines.

Configuring your connections:

1) Right click on Network neighbourhood and go to properties
2) First check if NetBEUI is installed, if not then click on Add + protocol +

In the vendors list choose Microsoft then select NetBEUI then press ok if it says restart your computer then do so.

Then go to my computer Dial-up network

Click on your dial up connection right click go to properties

Switch from general tab to the **server types**

Finally

All you need to do is download a Net BIOS scanner.
