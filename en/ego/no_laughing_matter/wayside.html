a humerous play on words.

WAYSIDE CHAPEL
--------------

While visiting in Leavenworth an English lady was looking for a room and
asked the local minister if he could recommend a place. He took her to
several rooms and when everything was settled the lady returned home to
England to make final arrangements for her move. After arriving home the
thought occurred to her the she had not seen a toilet, or water closet
(W.C.) so she wrote to the priest asking if there was a W.C. around the
place.
Upon receiving the letter, the minister puzzled over the meaning of
"W.C." and finally arrived at the conclusion the " W.C. " meant
Wayside Chapel. He then wrote the following letter to the English lady.

____________________________________________________________________________
| |
| |
| Dear Madam: |
| |
| I take great pleasure in informing you that a W.C. is situated 9 |
| miles from the house in the center of a beautiful grove of trees, |
| surrounded by a lovely grounds. It is capable of holding 229 people and |
| is open only on Thursday and Sunday. As there are a great number of |
| people expected during the summer months, I would suggest you come |
| early although there is plenty of standing room. This is an unfortunate |
| situation, especially if you are in the habit of going regularly. You |
| will, no doubt, be glad to hear that a number bring there lunch and |
| make a day of it, while others who can afford it go by car and arrive |
| just in time. I would suggest that your ladyship go on Thursday when |
| there is an accompaniment. The acoustics are excellent and even the |
| most delicate of sounds are heard by all. It may interest you to know |
| that my daughter was married in the W.C. and it was there that she met |
| her husband. I can remember the rush for seats. There were 10 people to |
| each seat, and it was wonderful to see the expressions on their faces. |
| |
| The newest attraction is a bell, donated by a wealthy resident of the |
| district. It rings every time a person enters. A bazaar is to be held |
| soon to provide plush seats for all since it is a long felt need. My |
| wife is rather delicate so she cannot attend regularly. It has been |
| almost a year since she last went and, naturally it pains her very much |
| not to attend more often. I shall be glad to reserve the best seat for |
| you, if you wish, where you can be seen by all. For the children, there |
| is a special time and place so they won't disturb the elders. |
| |
| I hope I have been of service to you in this matter. |
| |
| |
| Yours truly, |
| |
| The Minister. |
| |
