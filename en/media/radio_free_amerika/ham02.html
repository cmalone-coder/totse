Teletype and the Baudot Code
by THE RESEARCHER

TTY and TDD sent over phone lines uses 1800 Hz for space and 1400 Hz for mark. By comparison, yr 300 baud modem uses these frequencies: Originate (space-1070 mark-1270), Answer (space-2025 mark-25). TTY/TDD is sent at 60 words per minute (45.5 baud). Like RTTY, it uses a five element Baudot cdewhich bears no resemblance to ASCII. I had to build my own demodulator and keyer to check out thi inormation.
If you want to check out RTTY, you will need a communications quality short wave receiver and aemodulator. There is some good information on RTTY in chapter 5 of "Specialized Communications Techiues for the Radio Amateur".
If you want to explore these areas of telecommunications, you will need more information than Ian give you in a short article. The book I mentioned is a good starting point.

With only five elements to work with, the maximum number of combinations is 32. To expand the nber of characters which can be sent, two of the combinations are devoted to special signals called ltters" and "figures". When a "letters" signal is sent, the receiving equipment knows that the charctrs which follow are to be interpreted as letters. If a "figures" signal is sent, it means the chaactrs which follow are figures (numbers and puntuation marks). For example, the code for "H" and "# arethe same. Which character is printed is determined by wether it was preceded by a "letters" or figurs" code.

I was recently asked by a young hacker to post the EBCDIC character code. Since I am posting tecommunications codes this seems like a good place to include it. If your terminal program includes rnslation tables, you can use these codes to communicate with computers that use this system.
