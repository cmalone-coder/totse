File listing for NeoPagan archives on ftp.lysator.

[File name: /pub/religion/neopagan/current_files.]
[Last update: March 4th, 1994. ]

These are the files available via anonymous ftp from the
/pub/religion/neopagan directory on FTP.LYSATOR.LIU.SE. If you have
World Wibe Web or gopher you can use those. For gopher we use the
standard port, which is 70 whereas for WW we use the non-standard port
number 7500. There is also a mailserver. For more about it send mail
to ftpserv@lysator.liu.se with help in the body of the mail.

Separate listings of /pub/religion/foo will be sent to alt.foo, where
foo is satanism and discordianism RSN. General occultism files are in
/pub/magick. A listing will be sent to alt.magick, RSN too.

Questions about these files (and offers of other files of interest to
the NeoPagan community) will be happily received by me at:
ceci@lysator.liu.se. Please direct questions about ftp to your local
system's guru (try postmaster@your.site).

Files ending in ".gz" are compressed with gunzip. If you don't have
access to gunzip, you can transfer the files uncompressed, if you just
state the file name without the extension ".gz". This will take
considerably more time and bandwidth than transferring them in their
compressed form, but is useful if you don't have access to gunzip.

The READ_ME files contain information about the files in that
directory. The .message files contain information about our unzipping
software and are displayed automatically when you list the
directory. My comments are [in brackets] and up to date. --Ceci
